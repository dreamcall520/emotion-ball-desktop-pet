# 球球桌宠

一个免费、非商业使用的 macOS 桌面宠物。球球会悬浮在桌面上，可以拖动、点击互动、睡觉，也可以从菜单栏调整大小和行为。

## 主要功能

- 单击随机触发弹跳、旋转、开心等趣味动作
- 双击随机开心连跳、果冻抖抖、左右扭扭、歪头探望或点头鞠躬，低频旋转；睡着时双击唤醒
- 拖动球球到桌面的任意位置
- 鼠标眼神跟随、摸头和拖放反馈；系统活跃时保持清醒
- 离线互动气泡，可回应“再来一次”完整重播刚才的双击动作，或“你歇会儿”停止动作
- 支持超小（60 × 60）、极小（80 × 80）、紧凑（108 × 108）、小、中、大六档尺寸；首次启动默认极小
- 支持始终置顶、开机启动和位置重置
- 定制经典、云朵、幻彩、方糖四种外观，调整配色、透明度并保存启动外观
- 从本机 Codex 自定义宠物列表选择形象，预览原动画并保存；导入后使用球球本地副本
- 本机便签与待办，支持桌面便签、收藏、搜索、截止日期、提醒、归档和回收站
- 普通桌宠无需登录，可离线使用；主动使用聊天时，会把输入的消息发送给 Codex 生成回复

0.3.25 新增“定制球球”，支持四种外观、立体幻彩与简色渐变、实时预览和保存；聊天头像同步当前外观，并优化桌面互动与靠边展示。

0.3.17 新增“和球球聊聊”：使用本机已登录的 Codex 账号，关闭重开继续原聊天；支持历史记录切换、新聊天确认和预设动作回应，并修复任务监控误跟随自家聊天造成的连接占用。

0.3.14 新增左右靠边收起：拖到边缘露出圆润的小半身，鼠标靠近时探出，拖离恢复；收起时保留约 2.5–5 秒一次的眨眼和轻微呼吸，偶尔出现短句。开启 Codex 额度显示后，靠边时会间歇弹出真实剩余额度的小胶囊。菜单支持暂时隐藏和恢复，隐藏及锁屏时保持安静。

0.3.13 增加随桌面位置朝向内侧的眼神、睡眠效果和单侧互动；摸头会侧躺贴贴，放下后转面站稳，唤醒时醒脑一圈。Codex 执行中每轮展示约 6 秒的头顶短光迹，再安静 25–35 秒；单击可主动查看思考反馈。本轮完成随机跳跃或甩出原生渐变彩带，新增文案保留原有内容并避免连续重复。额度卡片继续只统计通用 `codex` 的 5 小时/周额度，原有周期选择与浅深外观设置保留。

“Codex 联动”仍为内测功能，默认关闭。开启后可查看额度与最近任务进展，球球用轻动作和气泡提醒；不使用 Codex 的用户无需开启。未打开后台任务及部分真实状态仍待验，读取范围、隐私说明和已知限制见[桌宠使用说明](desktop-pet/README.md#可选-codex-联动内测)。

## 下载安装

提供 Apple 芯片版与独立 Intel x64 构建，需 macOS 12 或更高版本。请按 Mac 芯片选择对应附件；Intel 的实机验证范围见 Release 说明。

当前 Apple 芯片版为 [0.4.01](https://github.com/dreamcall520/emotion-ball-desktop-pet/releases/tag/v0.4.1)，Intel 下载继续使用 [0.3.13 构建候选](https://github.com/dreamcall520/emotion-ball-desktop-pet/releases/tag/v0.3.13)。本次没有发布新的 Intel 安装包。

1. 前往 [Releases](https://github.com/dreamcall520/emotion-ball-desktop-pet/releases) 下载最新的“分享用 ZIP”。
2. 解压 ZIP，得到“球球桌宠.app”；也可下载并打开 DMG。
3. 将“球球桌宠”拖入“Applications”。
4. 如果 macOS 提示无法验证开发者，请打开“系统设置 → 隐私与安全性”，在安全性区域选择“仍要打开”。

该版本没有经过 Apple 公证。只有在确认安装包来自本仓库时，才建议执行第 4 步。

## 使用方法

- 单击：随机趣味动效
- 双击：多种全身动作；睡着时唤醒（手动睡眠在右键菜单中）
- 拖动：移动球球
- 右键球球或点击菜单栏图标：调整尺寸、置顶、开机启动、重置位置或退出

更多说明见 [桌宠使用说明](desktop-pet/README.md) 和 [分享安装说明](desktop-pet/分享安装说明.txt)。

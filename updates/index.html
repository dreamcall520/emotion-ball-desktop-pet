0.4.01 Apple 芯片版

Apple 芯片 · ZIPApple 芯片 · DMG

本次更新仅适用于 Apple 芯片；Intel x64 最新公开构建仍为 0.3.13 候选。

1.【新增】Codex 宠物导入

  • 在「来定制球球」中直接选择本机 Codex 自定义宠物，无需上传文件。
  • 预览满意后保存，桌面形象与聊天头像同步切换。

2.【升级】动作预览与尺寸同步

  • 支持九类动作预览，可暂停或继续播放。
  • 定制页与「球球尺寸」菜单共用六档大小，调整后同步生效。

3.【优化】查找与外观保存

  • 宠物列表支持内部滚动，超过六个时可按名称搜索。
  • 导入后保留本机副本，来源移除后仍可使用；可临时换装，也可保存为启动外观。

0.4.00 Apple 芯片版

Apple 芯片 · ZIPApple 芯片 · DMG

本次更新仅适用于 Apple 芯片；Intel x64 最新公开构建仍为 0.3.13 候选。

1.【新增】便签与待办

  • 支持桌面便签、分类管理、收藏与搜索。
  • 待办可分别设置截止日期和提醒，支持稍后处理。
  • 支持归档与回收站，方便找回记录。
  • 支持 Codex 智能整理，预览确认后替换内容。

2.【新增】来定制球球

  • 全新定制界面，实时预览外观。
  • 自由调整形态、配色、透明度与尺寸。
  • 保存专属启动外观。
  • 聊天头像同步展示球球形象与动效。

3.【新增】自动更新提醒

  • 自动检查并提醒新版本。
  • 点击更新入口，前往版本下载页面。
  • 关于页支持查看版本与手动检查更新。

4.【升级】额度卡片 2.0

  • 分别查看套餐额度、额外点数与 API 费用。
  • 支持查看额度趋势和用量预估，不同使用场景提供相应提示。
  • 支持查看重置机会与历史记录。
  • 展示进行中任务与待查看结果，点击返回对应 Codex 会话。

5.【升级】全局 UI 升级

  • 统一聊天、便签、定制页与额度卡片的视觉风格。
  • 优化浅色、深色与色弱友好配色。
  • 精简信息排版，统一按钮与操作入口。
  • 优化玻璃质感、边框与流光动效。

6.【修复】已知体验问题

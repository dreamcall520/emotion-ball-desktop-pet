球球桌宠 功能介绍

隐私说明

更新日期：2026 年 11 月 1 日

本说明介绍球球桌宠的本机数据与可选联网能力，并说明官网交互演示与本地设置。不同版本的可用功能，以你安装的版本为准。

Mac App Store 0.4.12 首发说明

本节专门说明 Mac App Store 0.4.12 首发构建的数据处理；下方跨版本说明中涉及其他工具、随包聊天组件或插件的内容，不适用于这一首发范围。此说明不代表该构建已经上架。

该版本仅提供 Codex 额度、聊天和可选的原工具任务日志同步，不包含 Codex 程序，不提供 ZCode、WorkBuddy、API 费用与余额查询或便签智能整理。桌宠、定制、便签待办和番茄钟可独立使用，天气也不依赖 Codex 登录。

连接 Codex 时，需要你已安装并登录 Codex.app 或 ChatGPT.app，并通过系统窗口分别允许球球使用所选原应用及本机 .codex 账号目录。球球保存对应系统目录访问书签，调用原应用内的官方组件复用原登录查询额度和提供聊天；不复制登录凭据，不建立球球独立的 Codex 登录，也不主动登录、退出或切换原账号。

上述账号客户端授权不是纯只读授权：原应用的官方组件可能在原 .codex 目录更新运行日志、会话或缓存。原工具任务日志同步另行征得只读用途许可，仅解析部分任务的必要标题、状态和更新时间；取消任务同步不影响已连接的额度与聊天。

连接本身不会自动发送模型消息。首次发送聊天前会单独说明发送对象与数据范围并请求同意；你主动发送的消息、必要对话上下文及主动问及天气时的天气摘要，会由 OpenAI 服务处理，并可能消耗原账号额度。数据处理和服务端保留以 OpenAI 隐私政策及账号设置为准。球球本机保存的记录不代表服务端不保留记录。

天气功能会向 Open-Meteo 发送所选位置经纬度以查询天气和空气质量，城市搜索会发送输入的城市关键词。使用当前位置需另行系统定位授权，也可以拒绝定位并手动选择城市。

主动提交的反馈内容、联系方式、所选图片与勾选的环境信息，以及默认开启的有限异常诊断报告，会发送并保存在球球反馈服务。异常诊断可在设置中关闭，不自动发送截图、聊天和便签正文；网络请求仍可能使服务方接触 IP 地址等信息。当前不承诺未经确认的固定保存天数。

你可以撤销球球的目录访问、关闭任务同步或异常诊断，并管理本机记录；撤销不等于退出原工具账号或删除原工具及第三方服务中的记录。需要处理或删除已提交的反馈、图片或诊断记录，可通过 920022027@qq.com 联系作者申请，并提供可定位该记录的信息。

一、本地桌宠与系统状态

普通桌宠不需要登录。

不读取输入内容、剪贴板或其他窗口，也不会上传个人数据。

鼠标坐标、系统空闲时长和锁屏状态只用于动作与休息判断。

二、便签、待办与本机记录

便签、待办、聊天记录与外观偏好保存在本机。便签和待办的记录管理、回收站与提醒，由对应功能处理；提醒需球球保持运行。

使用便签的智能整理时，内容按第四节所述交由 Codex 处理。

三、可选的 AI 工具联动

默认关闭，关闭后立即停止读取并清理当前监控状态。

Codex 任务监控只提取必要状态；额度趋势、待查看标记和重置记录仅保存在本机，不上传这些监控记录。

状态包可能附带已加载聊天内容，正文会立即丢弃；不会创建、发送、审批、中断任务或重置额度。

部分历史商店联调候选（不含 Mac App Store 0.4.12 首发）还提供 ZCode 与 WorkBuddy 联动。额度与设备任务历史按你选择的工具及授权范围查询；原工具目录的数据读取与任务插件安装是不同用途，原有只读许可不代表已经同意写入插件。官方套餐为空、权限不足或无法核实时，会保留相应提示，不推算可用额度。

任务插件需另行确认写入用途，并由系统目录授权允许访问原工具目录。球球仅安装随包提供的固定插件及必要的插件注册和启用设置；安装时需先保存工作并退出原工具。不会要求你配置终端或服务。

ZCode 与 WorkBuddy 的 Hook 输入可能包含提示词或上次回复；球球插件只在本机内存中处理、过滤，向本机球球传递会话编号、事件阶段、轮次等必要任务元数据，不把提示词、回复正文、文件路径或登录凭据作为任务事件保存或发送。插件不读取聊天正文文件或独立凭据文件；原工具自身可能按其 Hook 机制生成临时对话文件，其保留与清理由原工具决定。

任务停止或主回复结束不一定表示所有任务最终完成，具体状态以工具卡的说明为准。聊天与便签智能整理由你主动发起，按下方说明单独处理。

四、聊天与便签智能整理

聊天需联网。你主动发送的消息及延续当前对话所需的上下文，会交由你在球球中选择并授权的 Codex、ZCode、WorkBuddy 或自定义模型服务处理；不同版本的可选工具可能不同。便签智能整理仍由 Codex 处理当前便签内容。聊天或整理会消耗对应第三方账号的套餐、积分或 API 额度，具体计费与可用范围由该服务决定。

聊天记录与便签保存在本机。球球不会为了聊天自动读取原工具中的其他对话或其他便签，也不会运行模型返回的代码或命令。你主动问及天气时可能发送所选天气摘要，范围见第六节。

仅在历史随包组件的商店联调候选（不含 Mac App Store 0.4.12 首发）中，包内 Codex 与 WorkBuddy 聊天组件通过各自官方页面由你本人登录，登录状态保存在球球自己的本机配置中，与原桌面工具配置分开。ZCode 与自定义服务按已授权的配置连接；使用自定义服务时，消息会发送至该配置指定的模型服务地址，不应默认视为发送给 OpenAI。

发送前请确认所选服务及数据范围。第三方可能根据其服务条款、隐私政策和账号设置处理或保留输入与回复；本机保存不代表第三方服务器不保留数据。Codex 的相关说明见 OpenAI 隐私政策；其他服务请在其官方登录页面或你配置的服务方查询相应政策。

五、可选的 API 费用与用量报告

报告与常驻卡由你主动连接、开启。查询需要组织所有者提供具有费用与用量读取权限的 Admin API Key，默认查询范围是对应组织。

密钥在本机加密保存，用于连接对应的 API 服务；报告只提供费用与用量信息，不代表账号余额或最终账单。

六、可选的天气与位置

开启天气后，球球会向 Open-Meteo 发送所选位置的经纬度（当前位置或手动选择的城市），查询天气预报与空气质量；搜索城市时会发送你输入的城市关键词。

使用当前位置需系统定位授权，并调用 macOS 的定位与地名解析服务；也可以手动选择城市。

所选位置与天气缓存保存在本机，关闭天气后停止后台刷新。你主动问及天气时，可附带所选城市与天气摘要交由所用聊天服务处理。

七、官网演示、本地设置与访问统计

官网中的聊天、便签、定制与额度界面为交互演示，示例数据仅在网页内存中处理，不连接真实账号、模型或账单；刷新页面会恢复示例。

官网在浏览器本地保存主题选择。

正式官网的指定页面（包括本隐私页）使用 Umami Cloud 与 Google Analytics 4（GA4）统计访问及下载入口点击，用于了解页面使用情况。统计仅在 qiuqiu.pet 的 HTTPS 页面且配置已启用时加载，本地预览与交互演示不加载这些统计脚本。

官网统计代码仅发送经过筛选的访问与点击字段：页面路径（Umami 统一汇总为首页）、站外来源网站、浏览器语言、屏幕尺寸，以及下载入口、架构、来源和版本等；GA4 另保留白名单内的推广来源与媒介，不发送完整网址查询参数、页面锚点或表单正文。统计请求本身仍会让服务方接触 IP 地址及浏览器等网络信息；不能将字段过滤理解为没有任何第三方数据处理。

GA4 使用第一方 Cookie 区分浏览器和会话，官网配置关闭 Google Signals 与广告个性化信号。服务方也可能利用网络信息生成粗略地区和设备统计；其处理方式参阅 Google Analytics 数据保护说明及 Umami 指标说明。这些网站统计不发送球球 App 内的聊天、便签或账号资料，也不发送反馈文本、联系方式或所选截图。

官网脚本尊重浏览器的 Do Not Track（DNT）信号；检测到 DNT 已启用时不加载上述统计。浏览器本地停用标记也会阻止加载；修改停用设置后需重新加载页面。统计服务不可用不影响页面使用或下载。

八、数据管理与联系

你可以关闭状态联动、断开工具连接或撤销球球保存的目录访问授权，并在对应功能中管理本机便签、待办和聊天记录。联网 AI 能力由你主动发起，普通桌宠可继续独立使用。

以下独立登录配置及插件说明适用于提供这些能力的历史联调候选，不适用于上方 0.4.12 首发范围。目录授权记录、球球独立登录配置、聊天记录和任务元数据保存在本机各自的配置或缓存范围。断开接收或撤销目录授权不等于删除已安装在原工具目录中的插件及设置，也不等于清除球球已保存的全部记录、退出原工具账号或删除第三方服务器记录；需要时请分别管理这些记录及原工具插件。第三方账号和服务端数据的删除或撤销，需按对应服务的正式入口处理。

通过意见反馈主动提交时，你填写的反馈、使用环境、联系方式及选择的截图会发送给球球作者，用于排查问题与改进产品；这些内容不会公开展示。未选择的文件、聊天与便签内容不会随反馈自动上传。

App 的自动异常上报默认开启，可在意见反馈中关闭。开启时仅发送白名单内的功能类别、错误类型和错误码、应用版本、系统与架构、发生时间及计数、反馈编号和用于归类的故障指纹，用于排查稳定性问题；不自动发送原始错误文本、完整堆栈、聊天、便签、联系方式或截图。

App 在服务端确认主动反馈提交成功后，会在本机保存最多 100 条提交记录，包括反馈编号、类型、标题与描述、提交时间、截图数量和版本；截图内容不会存入该本机提交记录。重启后可在意见反馈的已提交记录页查看。

如对本说明或球球的数据处理方式有疑问，可通过 920022027@qq.com 联系作者。

# 0.3.21 文字可读性验收

2026-09-23，在 Apple 芯片 Mac / Electron 43.4.1 验证。本次为本机安装版本，未更新公开 Release 或官网。

## 改动

- 正常深色额度卡提亮主、辅文字，周期徽标改为白字和半透明深蓝灰底，减弱左上局部白色高光。卡底透明度、玻璃质感、流光、位置和尺寸保留。
- 靠边额度补齐“偏低 / 紧张 / 已用尽”，按未取整的余额判断。额度提示窗口最多 284×44，普通短句仍为 244×44。
- 球球原始造型、浅色及色弱友好配色均未改动。

## 验证结果

- 1048 项单元测试通过。
- 15 组隐藏原生渲染：白色背板下，折叠“额度”最低对比度由 3.44 提高至 5.48，“周”由 1.99 提高至 4.93；展开 CODEX 由 2.99 提高至 4.85。本轮正常深色文字采样最低 4.59。浅色及色弱友好样式、元素位置尺寸与修改前一致。
- 252 组额度布局、4 次跟随系统切换、4 种外观组合流光运动通过。
- 最终包执行 `verify-color-vision.js`：浅/深色 × 原色/红/绿/蓝色觉缺失/无色觉模拟，424 项文字和布局检查、160 项模拟色板对比检查通过。涵盖主卡、靠边两侧及双周期、聊天错误、禁用发送按钮和气泡。检查实际截取像素，确认模拟已生效；模拟色板文字对比最低 5.56。
- 最终包模拟聊天、角色外观不变检查通过；75 个运行文件与源码一致，严格代码签名检查通过。

对比度使用文字颜色与渲染背景或独立模拟色板计算，不代表字形抗锯齿每个像素的对比度。色觉模拟用于开发检查，不能代替真实色弱用户验收；不会给用户界面套滤镜。

## 复查

`verify-color-vision.js` 使用临时用户目录、隐藏原生窗口和模拟数据；不读取真实聊天，不发送模型消息。通过 Electron 运行：

```sh
npx electron desktop-pet/scripts/verify-color-vision.js
npx electron desktop-pet/scripts/verify-quota-accessibility.js
```

可用 `PET_VISION_APP_ROOT` 指向安装包内 `app.asar/desktop-pet`；`PET_VISION_ARTIFACT_DIR` 设置输出目录。默认在 `desktop-pet/build/color-vision-evidence` 生成结果、截图和 `index.html`。

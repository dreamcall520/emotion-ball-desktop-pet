## 入口和数据

球球菜单 → 日历 → 打开日历 / 常驻菜单栏 / 桌面小组件 / 日历设置。桌面展开、菜单栏与四款可选组件共享来源设置和数据，各自浏览日期独立。组件关闭后不自动复活；退出 App 保留已启用组件和位置。

新安装默认开启“常驻菜单栏”，只显示日历入口，不自动展开窗口或请求日历授权；已有明确关闭的选择继续保留。菜单栏日期文字仍默认关闭。

年月跳转与截止日期、提醒时间均使用当前主题控件。年月选择直接在弹层中切换年份和月份，支持键盘、回本月及 1970–2100 年范围校验；确认后才切换，取消不改变当前月份。

桌面月视图相邻月份的 1 日补充月份标识，如“12月1日”；当前月份 1 日按普通日期显示，其他日期和前后月原有样式保持。月初遇到今天仍保留圆形日期标记；菜单小窗与小组件布局保持。

法定放假和补班与普通节日分开：2026、2027按已核实的国务院通知逐日标注“休／班”，连续假期在同一周横向合并、跨周续接，不计入个人事项数。窄窗口与菜单小窗显示紧凑标记；普通周末、元宵/七夕等节日不直接推为假期，其他年份不推断。节日首日和工作日提醒原逻辑保持。

数据依据：[2026官方通知](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)、[2027官方通知](https://chinajob.mohrss.gov.cn/h5/c/2026-11-09/635850.shtml)。

最后细节返修：假期横条改为跟随真实占位位置，保留下方间隔，窗口调整后重排；月视图默认直角，“今天”左侧的小按钮可切换6px圆角和2px间隙，选择会保存，其他视图和菜单小窗保持。小日程卡将同起止时段的多条标题合并时间，尽量显示今天的后续安排，同时保留待办铃铛；宽日程卡保持。菜单边界减淡、指针同色并加内高光，保留原生阴影与520×480内容尺寸；这是轻玻璃样式，未新增AppKit液态玻璃或权限。

薄荷绿、晴空蓝、暮光紫使用当前主题样式表；色弱友好使用当前无障碍变量。浅色、深色、跟随系统为独立外观设置，初始主题在窗口加载前注入。现有球球图标保持原样，日历状态项使用标准日历符号。

待办直接使用现有 notes store；截止日优先，其次有效提醒日期。新建仅写截止日期，不创建提醒；完成状态双向同步，提醒仍由既有引擎处理。今日天气直接使用现有天气服务状态，不增加单独接口调用。

系统日历为 EventKit 只读使用：程序只调用 status/connect/read，不包含写入 API。macOS 14+ 系统授权本身是完整日历访问权限，产品不得称“只读权限”。仅点击连接后请求授权；拒绝、撤销、锁屏时清除内存日程；日程不落盘。未授权时仍可使用月历、本地待办和天气。

## 边界

- UI 与 IPC 限于当前受管窗口的主 Frame 和本地页面，不允许任意 URL 或弹窗。
- 日历来源使用实际系统名称和颜色；空数组表示不显示任何来源。
- 菜单栏月历只显示日期、农历、节气和数量；桌面月历按可用空间展示数量、摘要或更多事项。
- 新建待办使用独立 dialog，保存前不写入；取消、Esc、遮罩关闭均不修改数据。
- 农历、节气不等同于法定休假，不显示未核实的休/班标识。
- 默认不启用菜单栏和桌面组件；用户显式开启后保存设置。

## 本轮返修

- 用户指定参照实际「定制球球」窗口：顶部轻主题洗色、主体白底、深色标题、浅底主题色按钮。撤回灰色方案和设置中心整屏蓝粉渐变，保留四套主题及浅深色。
- 桌面支持日／周／月／年。日周按时间排列日程，全天事项与待办独立显示；重叠事件分列、跨日裁剪。年视图显示十二个月日期总览，点日期进入日视图；不将尚未读取的月份当成零事项。菜单与组件保持月视图，菜单 520×480，左月历、右详情。
- 系统日历总开关位于日历设置；关闭后不读取，所有窗口清空系统日程并使旧请求失效，本地待办、月历和天气继续可用。来源筛选保留。
- 天气已有数据时打开详情；未设置城市时才打开选城。新建待办使用弹窗，保存后展开并定位新条目；今日摘要优先展示进行中／下一场。
- 节日与已核实假期首日每天最多一次互动，清明使用适当文案且不跳跃；预览不占当日额度。没有自动读取系统专注状态。
- 用户给定的 64 句原文分为早安、午餐、午休、下班四类，每类洗牌轮换、不连续重复，每类每天最多一次；时间可设，默认仅周一至周五。错过超过 30 分钟不补发。锁屏、隐藏、睡眠、专注及已有气泡时抑制，不打断当前互动。全局气泡关闭时不提醒。
- 桌面使用系统窗口按钮，菜单指向状态项；工具按钮有悬浮文案。日期文字可从菜单或设置关闭，桌面小组件开关入口保持。

## 可读性与布局细化

- 日历各窗口提升辅助文字对比度和必要字号；色弱友好模式的日期概览使用浅/深中性底与相应文字，不在深蓝底显示深色字。
- 日期概览保留原底色，外缘采用1px缓慢流光；色弱模式及减少动态效果使用静态边框，装饰不拦截点击。
- 桌面不再重复显示标题，保留系统窗口按钮、居中视图切换和右侧工具。本人最后指示将日周月年切换恢复上一版轻玻璃，设置分类仍用紧凑分段；工具按钮保留页面内轻玻璃。Electron未提供页面内单控件原生液态玻璃接口，本轮不增加AppKit桥，也不将CSS样式称为原生玻璃。
- 月格按真实可用高度容纳事项，不按窄栏固定为一条；余量使用下行“+N个”。年视图去除每月外框，随可用高度伸展，每月六行完整日期并以淡字补齐前后月，日期选中为圆点。日周事项条内缩且圆端。
- 四款常驻卡统一164高：三款方卡164×164，宽卡344×164；按最新指示关闭小组件原生阴影、淡化外边，保留原位置和开关。参照便签仅顶部淡主题色向主体底色渐隐，月卡日期网格利用全高且数字加粗，日期卡顶部居中、字体加粗，农历竖排在大数字右侧；空态居中，宽卡空态通过右下轻文字按钮打开完整日历。带铃铛的待办摘要为“今日 N 项待办”，整句主题强调色。
- 日程卡日期头按参考采用日期＋两行农历日＋两行星期的紧凑排列，细线分隔；“其他 N 项日程”前补竖线，数字两侧保留空格。
- 日程卡优先展示今天尚未结束的事项；宽卡右侧最多三条今天事项，再预告明日数量，今天少于两条时显示明天第一条。左侧空位优先预览一条今日待办，无待办且空间允许时补第四条今日日程，余量扣除已展示项。小卡最多两条同日事项，并按真实可用高度给待办摘要留空间。
- 新建待办的日期选择改为主题小月历，支持清除、今天、月份前后切换、方向键与PageUp/PageDown；日期仍必填，取消不会保存。已完成入口固定可见，按所选日期过滤，可展开与恢复。
- 日历设置分为显示与窗口、日历来源、球球互动三个顶部分类；来源操作明确写“打开系统日历”。日历可在设置中心录制独立快捷键，默认不占用组合键。
- 菜单日期总开关仍默认关闭；开启时默认仅显示阳历，可多选农历与星期，勾选项保持可操作。取消最后一种格式时同步关闭总日期显示，下次开启从阳历开始；旧总开关及已选组合保持。非当月日期使用可读的灰字与淡中性底，区别于当月日期。
- 预览反馈用弹窗内的短暂toast，约4.2秒后隐藏，不额外占用底部排版；同一失败可在再次尝试时重新反馈。
- 日周表头、时间与全天栏跟随主题的浅/深底色，色弱模式的时间辅助线降淡且保留文字、事件及当前时间的辨识度。天气卡采用左温度／右天气与体感的布局，图标轻缓移动，遵循减少动态效果设置；待办数量与加号留足间距。设置中心的球球尺寸支持整行选择，仍走原尺寸保存入口。
- 设置中心「快捷键 → 快捷面板显示」可选择入口、拖排或上下移动，最多6个；默认保留原六项，天气与日历默认不加入面板。隐藏入口不清除其功能快捷键，列表/悬浮与数字键采用相同可见顺序；全关仍保留管理入口。偏好复用shortcutSettings.order/hidden，不另建存储。
- 快捷键页同时提供共享的启用快捷面板与面板形态控制；可见数量放在显示模块右上。日历工具按钮采用轻量页面内玻璃样式，保留色弱及减少透明度的实底回退；设置分类按最新要求也复用便签的紧凑分段样式，不再使用满宽胶囊或下划线。
- 天气快捷入口明确打开详情（无城市时选城），首次初始化的折叠尺寸不能清掉显式打开意图；天气卡隐藏状态和城市选择保留。浮动面板3/5个入口以宠物中轴对称、连续等角排布，2/4/6保留原布局；角落仍整体避让。
- 月格事项竖线为3px圆头，余量与事项文字同一左边距；菜单非当月底色独立略强于桌面。日程/待办分区标题试用设置中心同系渐变，置顶选中态复用工具按钮边缘，不额外加蓝描边。桌面便签顶部渐变贯穿到主体，便签/待办分段切换也统一轻玻璃材质，尺寸和保存行为不变。

# Meteocons weather icons

Source: https://github.com/basmilius/meteocons
Author: Bas Milius. MIT license included in LICENSE.

Selected fill SVG files from official @meteocons/svg and @meteocons/svg-static 0.1.0 npm distribution archives. Registry SHA-512 integrity was checked; exact local whitelist and SHA-256 hashes are recorded in SOURCE.json. The 22 night SVGs have a local moon palette adaptation: Moon-group blue edge/fill and its exclusive gradient stops change from #86C3DB / #72B9D5 to soft warm beige #F4E5BD / #DCC48A. Clouds retain their original cool whites; rain, snow, other graphics, geometry and animations are unchanged. Other SVGs remain unmodified. SOURCE.json records original upstreamSha256 and adapted sha256 values. The original MIT license remains included.

Only hero icons use animated files. Folded cards, hourly forecasts and weekly graphs use static files; reduced-motion uses static hero files. No CDN or runtime dependency.

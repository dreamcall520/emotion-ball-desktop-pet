# 球球桌宠（macOS）

球球桌宠是 Emotion Ball 的本地桌面版本。它会悬浮在桌面上，不需要登录，也不会联网发送数据。

## 怎么用

- 拖动球球：按住球球移动到想放的位置。
- 单击球球：随机触发弹跳、旋转或开心动作。
- 双击球球：随机打招呼、开心回应、害羞、弹跳或旋转；睡着时双击会醒来。
- 鼠标移动：清醒时会看向同一屏幕上的鼠标；停下后视线慢慢回正。
- 轻轻摸头：不按鼠标，在头顶来回移动一小会儿，会露出舒服表情。
- 气泡回应：互动时偶尔说句悄悄话；玩耍气泡可点“再来一次”或“你歇会儿”。
- 右键球球：打开快捷菜单，可切换动作、大小、置顶和开机启动。
- 菜单栏：屏幕顶部也会保留球球菜单；找不到球球时，可选择“重置位置”。
- 退出：在右键菜单或菜单栏中选择“退出球球桌宠”。

身体统一使用原睡眠态的灰白色，开心、摸头等表情也不再变黄；眼睛、渐变与阴影保留。

系统没有操作 5 分钟后发呆、10 分钟后困倦、15 分钟后自动睡觉。你继续移动鼠标或打字，它会保持清醒；自动睡着后恢复操作会醒来。右键菜单可选择“立即睡眠”，手动睡眠不会被普通活动打断，要双击或从菜单唤醒。

菜单新增“保持清醒”和“互动气泡”开关。前者取消自动休息；后者可关闭所有对白。普通气泡约 4 秒，带按钮的约 8 秒；主动陪伴文案至少间隔 10 分钟，不播放声音、不抢输入焦点。极小尺寸下气泡文字也不缩小。

活动判断只使用鼠标坐标、系统空闲时长和锁屏状态，不读取具体按键、输入内容、剪贴板或其他窗口。专注表情只是对“系统活跃且鼠标静止”的近似判断，不会判断你写了什么。

## 安装位置

日常使用建议放在：

`/Applications/球球桌宠.app`

项目生成的原始应用保留在：

`dist/球球桌宠-darwin-arm64/球球桌宠.app`

当前版本面向 Apple 芯片 Mac。它使用本机临时签名，没有提交 Apple 公证，只适合个人本机使用。

## 删除

先从菜单中退出球球桌宠，再把“应用程序”里的“球球桌宠”移到废纸篓即可。个人设置保存在 macOS 的“应用程序支持”目录中，删除应用不会自动删除设置。

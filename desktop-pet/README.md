# 球球桌宠（macOS）

球球桌宠是 Emotion Ball 的本地桌面版本。普通桌宠不需要登录，可离线使用；可选的 Codex 联动仅在用户开启后工作。

## 怎么用

- 拖动球球：按住球球移动到想放的位置。
- 单击球球：随机触发弹跳、旋转或开心动作。
- 双击球球：随机开心连跳、果冻抖抖、左右扭扭、歪头探望或点头鞠躬，低频旋转；睡着时双击会醒来。
- 鼠标移动：清醒时会看向同一屏幕上的鼠标；停下后视线慢慢回正。
- 轻轻摸头：不按鼠标，在头顶来回移动一小会儿，会露出舒服表情。
- 气泡回应：双击短句对应当次动作；“再来一次”完整重播刚才的动作，“你歇会儿”立即停止并归位。拖动也可随时中断动作。
- 右键球球：打开快捷菜单，可切换动作、大小、置顶和开机启动。
- 菜单栏：屏幕顶部也会保留球球菜单；找不到球球时，可选择“重置位置”。
- 退出：在右键菜单或菜单栏中选择“退出球球桌宠”。

身体统一使用原睡眠态的灰白色，开心、摸头等表情也不再变黄；眼睛、渐变与阴影保留。

首次启动默认开启“保持清醒”，球球不会因系统空闲自动睡着。关闭该开关后，系统没有操作 5 分钟会发呆、10 分钟会困倦、15 分钟会自动睡觉；恢复操作后会醒来。右键菜单可选择“立即睡眠”，手动睡眠不会被普通活动打断，要双击或从菜单唤醒。

菜单新增“保持清醒”和“互动气泡”开关。前者取消自动休息；后者可关闭所有对白。普通气泡约 4 秒，带按钮的约 8 秒；主动陪伴文案至少间隔 10 分钟，不播放声音、不抢输入焦点。尺寸包含超小（60 × 60）、极小（80 × 80）、小、中、大五档，首次启动默认极小；超小和极小尺寸下气泡文字也不缩小。

活动判断只使用鼠标坐标、系统空闲时长和锁屏状态，不读取具体按键、输入内容、剪贴板或其他窗口。专注表情只是对“系统活跃且鼠标静止”的近似判断，不会判断你写了什么。

## 可选 Codex 联动（内测）

0.3.10 本地安装包把额度、任务名称和任务状态等设置统一归入右键或菜单栏的“Codex 联动”子菜单。默认关闭；第一次开启及每次关闭后重新开启都会说明读取范围，并由你确认。GitHub Release 不随本地安装包自动更新。

- 开启后，“Codex 状态”里可看额度剩余比例、重置时间，以及最多 20 个“处理中”或“等你确认”的本机任务；不展示已完成历史和“最近提醒”。
- 额度只统计“通用使用限额”中 `codex` 返回的 5 小时/周额度，不把 GPT-5.3-Codex-Spark 等模型专属限额混入。自动模式有 5 小时数据时优先展示，同时返回周额度时展开可看两项；标准卡片手动选择 5 小时或周额度时只展示所选一项，缺失时不偷偷回退。“一直展示剩余额度”默认关闭，卡片默认小巧，外观默认跟随系统。未持续展示时，每新增使用 10% 提醒一次，已用达到 80% / 90% / 100% 时加强提醒。
- 可单独开启“完成提醒显示任务名称”；默认关闭。处理中轻轻摇摆，等确认时探望，本轮有结果时小跳，明确失败时轻抖。仅代表本轮状态，不表示整个项目完成。
- 气泡的“去看看”只在点击后打开对应任务；多任务时“查看任务”打开列表。“知道啦”收起提醒。不代你创建、发送、审批、中断任务或使用额度重置。
- 任务接口的状态包可能附带已加载聊天内容；球球只在本机临时接收并提取进展，正文立即丢弃，不保存、不上传。不会新增按键监听。Codex 的账号和额度读取仍由已安装的 Codex 自身处理。
- 没安装、没登录、接口不支持、连接断开或状态包过大时显示明确的不可用状态，不猜测额度和进度；单个超大任务不会拖垮其他可用状态。可手动刷新，至少间隔 10 秒。
- 自动提醒会合并、限频；睡眠、拖动、锁屏或正在互动时不打断你，过时提醒不补播。关闭联动会立即停止读取并清理它的状态、气泡和动作，普通桌宠照常工作。单独关闭“互动气泡”则保留联动菜单与轻动作。

联动依赖本机 Codex 版本提供的只读状态能力，兼容性可能随 Codex 更新变化。已在获授权的两条已打开任务上验证真实完成、合并气泡、跳跃与关闭清理；未打开后台任务仍可能无法读取，真实等待确认/失败/中断及实际跳转仍待验，请以 Codex 界面为准。常规自动检查使用模拟任务，不创建真实任务或消耗模型额度。

## 安装位置

日常使用建议放在：

`/Applications/球球桌宠.app`

项目生成的原始应用保留在：

`dist/球球桌宠-darwin-arm64/球球桌宠.app`

Intel x64 独立应用生成在：

`dist/intel-x64/球球桌宠-darwin-x64/球球桌宠.app`

两个版本都使用本机临时签名，没有提交 Apple 公证。Intel x64 版已完成 Rosetta 模拟烟测，尚未完成真实 Intel Mac 验收；其 Codex 联动默认关闭，也不列为 Intel 实机已验证能力。

## 删除

先从菜单中退出球球桌宠，再把“应用程序”里的“球球桌宠”移到废纸篓即可。个人设置保存在 macOS 的“应用程序支持”目录中，删除应用不会自动删除设置。

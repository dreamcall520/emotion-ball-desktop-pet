# 三家统一授权引导设计

用户2026-10-31明确批准前轮用户链路并要求直接落地，沿用现有隔离商店工作树，不再新增方案审批。

每家工具只有一个连接主入口，进入同一套引导：确认聊天账号/来源、允许读取额度任务、必要的原工具任务同步许可。状态按实际连接动态跳过已完成步骤；每次只执行本人点击的步骤，不自动发送测试消息，不默认切换账号或计费来源。取消或厂商缺口不清除其他能力；关闭可稍后继续，重启按持久授权重新投影。

工具卡同卡显示额度、任务、聊天三行及更新时间，部分成功明确标识。历史缓存不冒充实时；WorkBuddy主回复终态不冒充全部后台任务完成。各工具聊天记录独立，进入统一聊天窗；重复聊天表单/企业调试入口折叠到详情。

系统目录授权、官方登录、插件安装不绕过确认；球球准备目录和安装内容，尽量减少查找。厂商官方未开放路线不伪造成功，给准确缺口及单步修复。原工具与球球聊天可能不同账号，未核实名义归属不宣称同账号。

不改正式安装App、不push/merge/提交审核。最终MAS开发签名仍需真实团队和profile，Darwin候选不等同MAS验收。

# 球球 0.4.10 商店版：送审前用户路径核对

状态：以最新 main `eb3c1f4` 的0.4.10候选功能为基线，正在整合；尚不能确认全部功能无损，暂不送审。公开Release最新仍为0.4.09。

## 希望用户怎么用

1. 安装打开后，桌宠、互动、皮肤、定制、便签待办和番茄钟可直接使用，不因没接AI而被挡住。
2. 点“工具连接”，选择自己使用的工具，一个、多个或全部均可。
3. 选择只聊天，或同时连接额度与任务。未选择的能力不索取目录/插件权限，也不一直显示“未完成”。
4. 球球展示本次连接范围，已有授权自动跳过。官方登录由用户完成，系统目录窗口预定位；不复制路径、不配置终端、密钥或服务。
5. 已有完整匹配插件时直接复用；确需安装更新且原软件正在用，提醒用户保存并退出，再自动继续，不能强退。
6. 聊天首次发送时明确接收服务、当前会话上下文与计费，之后同账号、同接收服务不重复询问。便签整理是独立用途，第一次整理时再确认，不在启动时打扰。
7. 日常打开球球直接使用；重启、额度刷新和同服务普通模型切换无需再授权。换账号、换接收服务或主动撤销后，只处理对应工具，不重做全部工具。

“点一下启用授权”应是统一入口，不承诺代替系统授权和服务商本人登录。完整首次连接三家，仍可能需要三个系统目录确认、两家官方登录，以及插件更新时原软件退出；这些不能用技术测试或自动化替用户省略。

## 已经验证过的部分

- 原商店候选中三家聊天实际回复、ZCode/WorkBuddy原软件事件、目录授权重启恢复已验证。
- 随包固定插件实际沙盒写入、重复安装内容不变已验证，正式审核适用性仍待Apple判断。
- 第三方AI发送告知、拒绝不发送、便签拒绝不改原文、番茄钟开始/暂停/重置已有真实MAS检查。
- 上述证据属于旧基线商店候选，不能替代新0.4.10整合包的完整验收。

## 本轮核对：仍需收口的卡点

- 账号：球球独立聊天登录与原工具额度/任务账号可能不同；当前只提示范围，尚无完整换号/一致性确认链路。
- 接入：ZCode官方套餐空、官方聊天未验证；WorkBuddy网站积分不是原桌面完整用量，旧详情仍有不可用入口；任务最终整体完成仍未确认。
- 功能保留：API余额账户仍强制空列表；原Codex皮肤未按已有目录许可同步；官网版记录迁移缺验证。
- 验证：本轮能力选择、插件免退出、开机启动均为源码/专项已完成，尚无包含这些改动的0.4.10真正MAS整包验收。
- 送审：正式签名待本人钥匙串密码；还没有最终分发包/上传构建、截图、完整审核资料与隐私标签。0.4.10新增自动异常报告已补本地隐私文案，尚未部署；外部插件审核适用性、素材和第三方分发范围仍待收口。

最后两项不应显示给普通用户为“连接未完成”；属于研发/发布检查。

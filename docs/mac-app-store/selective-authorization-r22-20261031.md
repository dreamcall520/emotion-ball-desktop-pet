# R22 按需授权与可用能力先开放

用户确认：可选单家、多家或全部工具；能用的先开放，不反复授权或一直显示未完成。

## 用户路径

工具连接页勾选 Codex / ZCode / WorkBuddy，可全选，再点“启用所选授权”。串行处理必要确认，已有授权跳过；选择偏好仅保存在窗口本地存储，不作为权限凭据，不在重启后自动发起授权。仍可从单家工具卡查看/管理连接。

每一轮只尝试一次同一步骤。用户取消或操作未获实际授权时，暂缓该工具，不继续弹该工具的其他权限；其他所选工具可继续。停止后续连接后，当前确认可自行完成，迟到结果不启动下一项。窗口关闭后不自动恢复未结束授权队列。官网积分是可选补充，不自动打开额外登录。

聊天已就绪则卡片和引导里的聊天入口立即可用，即使插件正在等待原工具退出。点聊天会暂缓后续授权。工具卡只要一项能力确实就绪就显示“已可用”，不是要求三项都成功；各能力继续显示实际状态。账号变动/明确错误优先显示“处理连接”。

无套餐、不支持、安装后等待首次任务事件均不计入必须继续授权的步骤；连接设置结束不代表全部能力可用。插件安装完成与实时事件证明继续分开，停止事件不冒充最终完成。已就绪步骤不再提供重复授权动作；手动刷新和高级安装入口保留。

ZCode切换聊天来源时清除仅用于引导预览的旧来源就绪信息/旧套餐结果；返回已连接来源不重复登录。取消目录授权后，主进程不紧接着重试聊天登录。

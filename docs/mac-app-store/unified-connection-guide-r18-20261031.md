# 统一连接引导 R18

## 用户现在怎么用

1. 球球右键→工具连接。每家一张卡，分别显示额度、任务、聊天；展开任务详情直接查看已授权标题/状态。
2. 未连接点启用授权，未完成点继续完成连接。引导集中呈现账号、数据目录、必要的官网积分和原工具插件步骤；每次只执行本人点击的一步，已完成授权自动跳过。
3. 可暂时跳过、稍后继续、先和球球聊天。单项取消保留其他能力，不自动发送测试消息，不切换计费来源；ZCode官方套餐与自定义API明确选择。
4. 重启恢复已授权连接；已装插件等待新事件仍属已连接，当前任务结果显示待更新。旧记录/过期状态明确上次记录及当前待核实。
5. 各工具聊天走统一聊天窗，保留独立记录。额度/原任务与独立聊天账号归属未核对时在卡面说明，不能暗示必为同一账号。

旧原生菜单三家独立启用开关在商店候选隐藏，设置中心对应动作导向工具卡，再进入统一引导；普通版原流程不改。原始聊天诊断/企业能力折叠到详情。

## 审查修复

- WorkBuddy数据授权/后台恢复不再额外打开官网登录；官网登录只由明确登录动作触发。
- 连接互斥锁内才执行ZCode来源及启用偏好变更；BUSY失败不改来源。
- 停用网站连接时终止请求、关闭球球自有登录窗并清除旧汇总；不删除账号cookies，不宣称平台侧退出。
- 已成功的积分步骤刷新原会话，不重复登录；暂时断网也优先刷新。
- 引导内保留具体的等待本人登录说明。
- 两家事件接收器先停止再清理；磁盘清理失败也不能继续接收事件。
- 安装观察回执只保存version/observedAt，无账号、事件ID、正文、路径或凭据。R16原生已验证WorkBuddy安装事实迁移为过去安装观察，不迁移任务实时状态。
- 停用并删除连接后重新授权，原工具缓存须更新插件连接；正常重启复用原连接无需重装。此限制在引导说明，不承诺所有重新授权均免更新。

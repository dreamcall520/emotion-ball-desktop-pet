# 商店 ZCode 候选：本地授权与数据处理草稿

2026-11-22。本文件供当前开发候选审查，尚未发布到线上隐私页，也不代表 Apple 审核通过。

## 本机连接

连接由设置中心发起，先说明用途，再分别在系统原生选择器选择已安装的 ZCode App 和 `.zcode` 账号目录。取消不建立新连接。球球保存应用范围安全书签，以便重启后恢复；解除连接时撤销球球保存的授权。

球球调用用户选择的原厂组件，只读核对官方账号和查询套餐额度。新版凭据仅在本机原厂签名子进程内通过已有系统钥匙串项解密，并用于原有官方认证及额度接口；不会创建或迁移账号，不导出钥匙串主密钥，也不把令牌传给球球页面、诊断记录或球球运营服务器。球球主进程仅接收账号隔离摘要、套餐来源及规范化额度。查询前后核对账号，切换账号或撤销授权后丢弃迟到结果。

官方查询使用当前安装版的版本参数。体验／活动额度与个人、团队套餐分别展示；官方返回空集合时不构造额度桶。新版个人和团队套餐沿用官方会话方式换取短期项目令牌，再查询实际套餐；这一步包含原厂认证 POST，不等同纯 GET。不会新建长期 API Key、修改团队配置或切换计费来源。

## 本机任务

任务读取有独立同意，可单独撤销。复用已经授权的目录，仅查询本机任务名称、状态、更新时间及本轮标识，不读取聊天消息正文。当前官方数据库没有账号归属字段，因此不把设备缓存称为当前账号全部任务，不提供推测的运行总数。任务未授权时隐藏任务、旧结果和任务提醒计数，额度及额度趋势仍保留。

## 动画提醒

动画提醒有独立的目录选择和写入用途。球球仅安装自己的固定事件脚本及本机连接信息，更新 `.zcode/cli/config.json` 中对应 Hook，先备份原设置，不修改原厂 App 签名、账号或模型设置。重复启用不重复添加 Hook；关闭提醒移除球球添加的内容，保留其他设置。官方会话使用配置快照，因此启用后需要新建任务。

官方 Hook 输入可能包含提示词。脚本仅在有大小上限的本机进程内存中提取会话、轮次和阶段，不读取临时对话文件，不保存或发送正文、路径或凭据。元数据只发送到有随机授权口令的本机回环接收器，不发送给远程服务器。

UserPromptSubmit 仅证明观察到本轮开始，Stop 仅促发刷新。只有同一会话、同一轮次的官方 `turn_usage` 终态才结束本轮并决定结果提醒；失败、取消及缺失终态不冒报成功。长期没有新鲜证据时转为未知，重启不回放历史成功提醒。

## 聊天边界

主连接同意包含当前官方账号聊天。只有用户主动发送时，才把该消息、当前对话上下文和必要的城市天气摘要交给所选官方服务，使用当前官方套餐。聊天由授权的原厂 ZCode runtime 执行；凭据和短期项目令牌留在原厂签名子进程，不传给页面或日志。当前官方选择、账号和授权世代在请求及回调时持续核对，变化后停止旧会话，不自动改用 configured-custom、其他供应商或其他计费来源。Codex 与 WorkBuddy 沿用既有授权和发送规则。旧的仅额度同意不自动获得聊天发送权限，需要重新完成含聊天用途的连接说明。

## 删除与撤销

解除主连接停止额度查询、聊天和本机任务读取，并关闭对应动画接收与移除球球 Hook，忘记球球保存的本地书签和用途记录。原厂登录、账号、应用和其他配置不受影响。球球自己的聊天、额度历史及资料保留与既有本地数据管理行为一致，不额外承诺未实现的自动清除期限。

# 启用授权与聊天来源

用户已确认：每家只需点击启用授权，登录和系统权限本人确认，其余检测、连接与恢复由球球处理；不让用户配置终端、端口或服务。聊天由用户选择已授权工具，不自动替换账号或计费来源。

实现分工：
- `mas-enable-flow.js` 串行处理授权→数据读取→聊天连接，重复点击合并；重启恢复非交互，不弹登录或选择器。部分就绪与全部就绪分开。
- `mas-directory-access.js` 与诊断授权器预定位工具目录，验证旧授权，选错目录不覆盖旧授权。
- 工具连接页仅保留启用/撤销、状态与必要模型来源选择；聊天页三来源可见，未就绪引导授权。
- Codex官方开源固定版本组件随包，球球自有profile，stdio连接无配对文件；首次官方网页登录完成后自动连接，不复制原工具凭据。
- ZCode自定义通用API仅在用户显式选择且配置自包含、用途允许时直连；官方套餐与Coding专用渠道不互相替代。
- WorkBuddy优先核验官方MIT CLI随包托管；没有实际可用组件时明确部分就绪，不让用户运行服务。

验证：控制器取消/重入/非交互恢复/关闭失效；目录授权恢复与错误选择；真实Chromium来源与计费选择；官方Codex真实包内启动/官方登录/用户本人完成登录后聊天；最终包源码及签名。历史缓存不冒充实时任务；真实Electron MAS沙盒与商店审核另行验收。

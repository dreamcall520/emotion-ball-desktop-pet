- 本轮候选真实聊天成功，不是正式 MAS 签名二进制的沙盒验收。此前原生沙盒目录书签、HTTPS 与本机 TCP 探针分别见对应证据。

## 运行方式

1. 在上架工作树执行 `node desktop-pet/scripts/start-codex-local-chat-service.js`。
2. 打开独立候选的“工具连接”，明确选择 `.codex` 数据目录。
3. “导入本机连接”选择启动器显示的连接**目录**，不打开或预览 `pairing.json`；再点“连接聊天”。
4. 服务只监听本机，配对能力仅当次有效；退出启动器会清理其配对文件，不结束其他 Codex 进程。球球不会自动安装或启动外部服务。

测试中第一轮配对文件曾被系统文件选择器预览。该服务已停止、旧配对文件已删除；导入流程已改为选目录，新服务重新配对。未输出或复制供应商登录凭据。

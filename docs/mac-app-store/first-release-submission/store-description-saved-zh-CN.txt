球球是一位住在 Mac 桌面上的小伙伴。

内置小白、小宇等伙伴，保留各自的动作和互动。选择喜欢的形象，点一点和它互动；调整外观、实时预览、保存设置并收藏自己的形象。完整定制页面保留伙伴选择、额度样式、定制案例和开发者微信咨询。

在“Codex 宠物”中，可主动选择 pets 素材目录，将符合格式的素材复制到球球；素材导入无需先登录 Codex，不读取原聊天或登录凭据。“其他伙伴”保留本地素材文件夹导入。普通照片不会自动生成动态皮肤。

用便签和待办记下想法与事项，配合番茄钟安排专注和休息。这些本地功能无需 Codex 登录；待办提醒需要球球保持运行。

通过快捷面板进入常用功能，也可在设置中调整配色和显示偏好，使用意见反馈入口提交建议。

手动选择城市，查看天气小卡并展开或收起。需要使用当前位置时，再由你确认系统定位权限。

在球球内完成一次本人 Codex 官方登录，即可查看同一账号可读取的额度，并选择可用的 Codex 模型聊天。额度小卡和展开卡均保留，查看额度不需要额外授权原 Codex 目录。首次发送聊天前，会说明消息、当前会话上下文及接收服务，并询问你的同意。

如果需要同步原 Codex 软件的部分日志任务，可单独开启任务同步并确认目录权限；取消或不启用不影响已连接的额度和聊天。任务同步不保证覆盖原软件全部任务或全部后台工作。

Codex 联网功能需要有效账号及相应服务权限，模型和额度以服务实际返回为准，可能消耗对应账号套餐额度。球球是独立应用，并非 OpenAI 官方产品。天气等联网功能需要网络连接。

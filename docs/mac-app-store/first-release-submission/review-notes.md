## 应用用途及无需登录的功能

球球是独立桌面宠物与本地效率工具，Codex 为用户按需连接的第三方能力。桌宠互动、内置形象、完整定制页面、本地便签待办和番茄钟无需 Codex 登录。

1. 安装并打开 App，在桌面查看球球；应用采用桌面伙伴形态，不以常规主窗口作为所有操作入口。
2. 打开球球菜单，选择“来定制球球”。可在“球球外观”“Codex 宠物”“其他伙伴”“额度展示”中查看当前提供的功能。预览与保存使用现有原生应用页面。
3. 在菜单打开“便签与待办”或“番茄钟”，测试本地记录与专注计时。待办提醒需要 App 运行。
4. 从设置的天气入口手动选择城市，查看天气卡片；展开／收起均可用。定位仅在选择使用当前位置时请求，可拒绝后继续手动选城。

菜单标题与路径须在最终包回读确认后再提交；不得用源码存在代替实际可达。

## Codex 登录、额度和聊天

1. 在菜单选择“连接 Codex”，进入单 Codex 连接页。
2. 点击“连接 Codex”，由测试者本人完成官方登录。球球不要求复制密钥、输入端口、打开终端或安装原 Codex 任务插件。
3. 登录后查询球球内同一账号额度；连接页显示实际读取状态，桌面保留额度小卡及展开卡。查询失败时不回落为原软件其他账号额度。
4. 点击“和球球聊天”，选择该账号实际可用的 Codex 模型，输入测试文字并主动发送。首次发送前显示接收服务与数据用途同意；拒绝则不发送并保留草稿。
5. 同一登录、账号、接收服务及已同意用途有效时，后续普通聊天和重启恢复不重复要求全部授权。
6. 用户可以撤销聊天数据同意；下次明确发送时再确认。解除连接会停用联动并撤销本地任务目录及发送同意，当前不等同退出官方账号或更换账号。完整独立换号尚未作为已完成功能宣称。

Codex 功能需要有效的第三方账号和相应服务权限。账号的模型、套餐与额度可能不同，球球不能保证任意账号均有可用额度或特定模型。球球并非 OpenAI 官方产品。

## 可选 Codex 宠物素材目录

此操作与 Codex 登录、额度查询和任务日志是不同用途，不合并为同一目录权限：

1. 在真正 MAS 构建的定制页打开“Codex 宠物”，点击“连接 Codex 宠物目录”；已有连接时显示“更换 Codex 宠物目录”。
2. 系统文件夹选择器预定位原 Codex 的 `pets` 素材目录，由使用者本人确认；可取消返回，原形象和其他功能保持。应选择含宠物子文件夹的 `pets` 素材库，而不是整个 Codex 数据目录。
3. 球球只读取选中素材库的普通直接子文件夹，验证 `pet.json` 和声明的 PNG／WebP 素材后复制到自己的容器；不修改原素材目录，不读取聊天正文或登录凭据。
4. 此能力保存独立、仅用于素材库访问的安全目录书签；刷新按已保存许可同步素材，不为该用途要求登录 Codex。已复制的素材可由球球本地使用。
5. 当前已在真正 MAS 开发包用隔离合成素材库验证取消、导入1只测试伙伴、选择预览及保存；重启后素材书签复用与伙伴恢复仍待测，最终分发包同样待验。普通 Electron 不具备所需安全目录 API 时，不显示这项 MAS 专用连接能力，不能用其结果替代系统授权验收。

这条素材库连接不同于“其他伙伴”的原有单个素材文件夹导入；两个入口均保留，不代表扫描原 Codex 全部用户资料。

## 可选原 Codex 任务目录

1. 只有在连接页点击“开启任务同步”时，才交互确认原 Codex 目录。
2. 用户可取消，不影响已连接的同账号额度和聊天。
3. 任务读取范围是已授权目录中的部分会话日志；来源与球球聊天独立，不宣称同账号、完整覆盖或后台整体任务终态。
4. 历史或失效记录据实显示为上次记录／当前待核实，不把重启旧记录冒充实时。

该首发构建不提供 ZCode、WorkBuddy 联动及两家插件安装，不在用户目录安装这些插件。实际仍静态依赖的 JS 不等同对用户开放这些功能。

## 完整定制及微信咨询实际行为

当前首发源码仍保留以下原有路径，没有采用尚在设计稿的“纯帮助与反馈”改版：

“开启专属定制” → “专属皮肤定制”案例与动作预览 → “添加微信咨询” → 微信号及二维码、复制微信号、保存二维码。

页面目前仍有“效果、费用与周期，沟通确认”和定制沟通流程。不能在审核说明中把它描述为只有故障客服，也不能因 App 免费就承诺这条销售路径当然适用。是否收费、制作交付内容、用户在何处使用、支付及发行地区方案，均须本人确认后依实际行为完善此段；确认前该项仍是提交前待决事项，不自动删除或隐藏用户要求保留的功能。

本地素材导入是用户选择完整素材文件夹；不代表普通照片自动生成、云端上传或购买后自动解锁。本地导入能力不应作为规避适用购买规则的渠道。

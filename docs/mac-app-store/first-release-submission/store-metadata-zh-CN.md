## 描述主体

让球球陪你待在桌面，也陪你把手边的小事慢慢完成。

**选一个喜欢的桌面伙伴**

切换内置形象，与球球互动，调整外观并实时预览。保存喜欢的设置，收藏自己的形象，也可以导入符合球球格式的本地伙伴素材。

在“Codex 宠物”中，可主动选择连接宠物素材目录，将符合格式的素材复制到球球；这项素材导入无需先登录 Codex，也不会读取原聊天或登录凭据。“其他伙伴”继续保留本地素材文件夹导入。

**记下待办，开始一段专注**

使用便签和待办记录想法与事项，配合番茄钟安排专注和休息。本地桌宠、便签待办和番茄钟无需先连接 AI；待办提醒需要球球保持运行。

**把天气留在桌面一角**

手动选择城市，查看天气卡片并按需展开或收起。需要使用当前位置时，再由你确认系统定位权限。

**用同一个 Codex 登录看额度、聊想法**

在球球内完成本人官方登录，查看该账号可读取的额度，在小卡和展开卡之间切换。打开球球聊天，选择可用的 Codex 模型，再输入想聊的内容。

额度和聊天共用球球内的同一个登录，不需要为查看额度额外选择原 Codex 目录。首次发送聊天前，会说明发送内容与接收服务，并询问你的同意。

如果还想同步原 Codex 软件的部分日志任务，可以单独开启任务同步并确认目录权限；不启用也不影响额度和聊天。任务同步不保证覆盖原软件的全部任务或全部后台工作。

**关于定制与使用条件**

定制页面保留形象设置、已有案例展示及开发者微信咨询入口。案例展示不代表所有案例都属于内置可直接使用的皮肤；素材导入需要完整、符合格式的素材文件夹，普通照片不会自动生成动态皮肤。

Codex 联网功能需要本人有效账号及相应服务权限，模型和额度以服务实际返回为准。球球是独立应用，并非 OpenAI 官方产品。天气等联网功能需要网络连接。

# 球球 0.4.10 首发提交资料草案

2026-11-01。此目录仅为本地送审资料草案，未上传 App Store Connect，未提交审核。以 `../first-release-implementation-20261101.md` 和当前 `mas-first-release` 源码为编写依据；草案不证明最终包已验收。

## 文件

- `store-metadata-zh-CN.md`：中文名称建议、副标题、描述、关键词、截图计划及待填字段。
- `review-notes.md`：审核员操作说明、登录与权限边界、完整定制及微信咨询的实际行为披露。
- `privacy-data-map.md`：当前数据流及App Privacy填写依据，未代填未知项。
- `acceptance-matrix.md`：最终首发包功能验收矩阵。尚未执行的最终包用例统一标待验。

## 当前范围

保留桌宠互动、内置皮肤、完整定制页面（含现有宣传及微信咨询）、本地素材导入、便签待办、番茄钟、天气卡片、Codex 额度小卡及展开卡、仅 Codex 模型选择的球球聊天、可选原 Codex 部分日志任务。首发不提供 ZCode、WorkBuddy、API 余额／费用、便签 AI 整理。

完整定制和微信咨询调整方案仍是项目设计稿预览，没有在本轮代码中采用。本草案如实披露原入口，不能在审核说明中改写成已成为纯客服入口。也不能声明全部代码、视觉或动画自研。

## 提交前必须回填

| 项目 | 状态 |
|---|---|
| 正式 Bundle ID、分发构建号、分发 pkg 摘要 | 待最终分发包确认 |
| 上架名称、销售方／版权文字、发行地区 | 待本人确认并后台回读（定价按本人说明为免费） |
| 实际最低系统版本、支持架构、下载体积 | 待最终分发包确认 |
| 公开隐私政策和支持网页 | 地址及内容待最终线上核对 |
| App Privacy、年龄分级与加密出口回答 | 待按最终数据流和功能填写，不默认“不收集数据” |
| 代码、角色、动画、依赖的分发依据 | 待核实；不以删除声明替代授权 |
| 微信付费定制路径的首发决定 | 待确认；当前实现仍保留原咨询及费用文案 |
| 审核登录条件与可用的演示资源 | 待本人安排，不在文档放密码／令牌 |
| 全新用户与最终首发包功能验收 | 见矩阵，未执行项不写通过 |

## 使用约束

只有实际最终包验证过、并与 App Store Connect 上传构建一致的行为，才可在正式描述与审核说明中作为已生效能力提交。草案中的“待确认”不得原样发布。最终审核与线上版本行为一致，不通过审核后静默开启其他提供商或恢复不同销售入口。

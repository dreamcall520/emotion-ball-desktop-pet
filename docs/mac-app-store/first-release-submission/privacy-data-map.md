## 2026-11-21 WorkBuddy 增量依据

下方首发表格保留为 2026-11-01 历史记录，其中“随包组件／独立 profile”“异常报告默认开启”等旧描述不代表当前构建。当前依据为 `b90401f` 商店候选及本轮仅补充文案的后续提交，详见 [WorkBuddy 数据流与政策依据](../workbuddy-privacy-20261121.md)。本轮未修改 App Store Connect 隐私申报，不把客户端或网页修订称为后台已更新。

| WorkBuddy 用途 | 数据与接收方 | 保留与撤销边界 |
|---|---|---|
| 本机连接与官方请求 | 系统选择的应用／账号目录；官方本机组件使用登录材料，官方请求含必要账号认证信息。球球保存访问书签及账号识别哈希，不复制账号 access/refresh token 到球球文件 | 撤销球球的连接许可不等于退出官方账号，不删除官方登录资料 |
| 积分与消耗 | 套餐、余额、分类、到期／刷新；从官方返回结果中只提取使用时间、积分和去重标识用于消耗统计。接收方为腾讯 WorkBuddy 官方服务 | 余额趋势按账号本地保存；当前消耗统计在内存处理。不能承诺官方响应不含正文，或断连后趋势文件被删除 |
| 聊天 | 主动发送的正文、当前对话上下文、必要系统提示；天气问题可能附城市／天气摘要；发送至 WorkBuddy 官方服务，消耗账号积分 | 本机 JSON 保存聊天正文与回复，未做应用层正文加密；“新聊天”归档旧记录，断连不删历史。第三方保留由其政策／账号设置决定 |
| 任务同步 | 独立任务目录授权；仅查询任务标识、名称、状态、未读及更新时间等元数据，不查询消息正文，不修改官方未读 | 当前列表在内存；球球“已查看”状态可持久化。撤销停止读取并清列表，不删除原任务或既有已查看文件 |
| 动画提醒 | 连接默认请求启用，但安装前仍须系统目录许可；原始事件输入可能含正文，脚本在本机过滤，只通过本机回环地址传标识、阶段和轮次等元数据 | 原始输入不写临时文件；本机保存配对信息。不能写“从不接触正文”“所有传输均 HTTPS”或“不保存任何 token” |
| 提醒安装与备份 | 注册自有 Hook／脚本／receiver；修改前完整 settings.json 备份留在原 WorkBuddy 配置目录，可能包含用户已有其他设置 | 停用移除自有 Hook 及内容未被修改的自有文件；备份和用户修改文件可保留，不承诺彻底清空所有副本 |
| 诊断 | 本地 errors.log 可含路径／堆栈；MAS 自动上报默认关闭，独立明确同意后仅发白名单诊断字段到球球反馈服务 | 关闭清待发送队列，不删除已提交反馈／诊断或本地历史；主动反馈的自选正文／图片不适用自动诊断的排除承诺 |

## 历史首发表格（2026-11-01）

这是按当前源码整理的数据流，不是已完成的App Privacy申报。不预填“完全不收集数据”。

| 功能 | 数据与接收方 | 触发与保留边界 |
|---|---|---|
| Codex登录、额度与聊天 | 用户本人经官方页面登录；官方随包组件使用球球独立profile。聊天正文、必要上下文及账号相关请求发送至对应OpenAI服务 | 首次明确发送前独立同意；本地保存聊天/profile；解除联动不等于官方登出或删除厂商记录。不能声称开发者获得用户登录密码 |
| 原Codex任务 | 已授权目录内部分任务日志／元数据 | 只有用户选择任务同步并确认目录后读取；不能写成读取原账号凭据来登录球球，也不代表所有后台任务 |
| Codex宠物素材目录 | 用户本人系统选择的 `pets` 素材库；读取其中普通直接子目录内的 `pet.json` 与已声明 PNG／WebP，并复制到球球容器 | 独立素材用途安全目录书签，仅在主动连接／更换或按现有许可刷新时访问；不修改原目录、不读取聊天正文或登录凭据，不与登录／额度／任务目录授权混为一项。已复制素材本地保留；本轮真正MAS开发包已验证隔离合成素材导入、保存、重启恢复及刷新无系统选择框；最终分发包和真实用户素材仍待验 |
| 天气手动城市 | 所选城市查询与天气坐标请求发给公开天气/地理服务（实际端点以最终包源码为准） | 不依赖Codex登录，无需先开定位；本地保存所选城市和缓存 |
| 天气当前位置 | 仅主动点当前位置后使用系统位置，再请求位置说明/天气 | 精确或粗略位置类别需按最终坐标精度与第三方实际处理方式判断；不能仅因不自建服务器就默认不需要披露 |
| 便签待办、番茄钟与定制 | 本地正文、待办、计时、外观和导入素材 | 首发无便签AI整理；普通本地使用不自动上传这些正文或素材。导入需要本人系统选择文件夹 |
| 手动反馈 | 用户输入内容、可选联系信息、所选图片及勾选的环境信息发至开发者反馈服务 | 用户明确提交才发送；测试本轮没有发送反馈、图片或私人内容 |
| 自动异常报告 | 开启时发送有限异常分类/名称/代码、版本、OS、计数和时间等字段；源码会先白名单投影，不发送完整原始错误对象 | 当前新装默认开启；需与App内开关、政策和后台数据保留实际一致。本轮只关闭了独立QA资料的开关，没有改正式用户设置 |
| 微信咨询 | 用户自己使用微信联系开发者 | 不能把二维码描述成App内支付，也不能隐瞒原页面存在费用/周期咨询；该销售路径仍待定稿 |

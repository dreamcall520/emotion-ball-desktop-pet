# 意见反馈与自动异常上报

入口：设置中心 → 意见反馈；右键菜单也可直达。使用现有设置中心的主题、卡片、按钮与开关。字段统一左标签、右控件；蓝／绿主题、浅／深色及620px窄窗均验证。

## 手动反馈

支持问题反馈、使用建议、功能需求；填写标题、说明，选填联系方式、最多3张截图（每张1MiB）。运行环境默认附带，可取消并展开查看，只含版本、系统、架构和Electron/Node版本。

提交经主进程验证，使用现有 `https://qiuqiu-feedback-entry.pages.dev/api/feedback`。仅服务端返回相同提交编号时显示成功。失败保留输入、附件和编号；切换设置分类也保留草稿。关闭窗口有放弃确认；草稿不跨应用退出持久化。

## 自动上报

默认开启；已有明确关闭设置继续保留，用户可随时关闭。复用主进程错误记录入口、窗口崩溃／无响应／加载失败／脚本错误事件，以及 `uncaughtExceptionMonitor`。报告失败不影响原有错误处理，不拦截程序默认异常退出。

只发送固定模块标签、白名单错误类型／错误码、版本、系统、时间及采样次数。不会发送原始错误消息、堆栈、日志、账号、密钥、路径、聊天、便签或自动截图。没有设备标识，不能统计独立影响用户。

首次2秒采样归并，成功后同指纹1小时限频。最多暂存20种错误；网络失败按1分钟至1小时退避，重启后补报。为保持服务端幂等，开始提交后冻结内容，次数不代表全量故障数。关闭立即取消自动请求并清除待上报记录；已被服务器接收的内容无法撤回。系统强制结束或启动早期异常不保证能够捕获。

现有管理列表中，自动报告为「问题反馈」，标题带 `[自动异常]`；指纹与采样次数可在详情查看。没有新增工单状态、通知或统计后台。

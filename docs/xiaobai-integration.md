# 小白皮肤与互动

本分支仅整理小白独立候选中已确认的角色素材、互动和相关播放能力。最初整理基线为 `30db465`；上传合并前已同步最新 `main` 的 `785b2f2`（贴边修复）。本文记录源码和测试，不作为安装或公开发布证明。

## 使用范围

- 皮肤名称为“小白”，导入后在形态选择中紧随“咩咩”。
- 抬爪、摇尾、舔爪、玩骨头、左右走跑、歪头待机、坐睡与趴睡。
- 小白双击随机互动，拖动时连续迈步，贴边适当多露出身体。
- 睡稳后在头顶间歇出现春野或伙伴梦境；唤醒或切换皮肤时清理。
- 任务完成时，跳跃、开心庆祝、快乐转圈各约三分之一概率；播完回到待机，取消时停止。

## 素材与导入

最终素材位于 `desktop-pet/assets/pets/xiaobai/`，包含 `pet.json` 和 12 张透明动作图集。通过“定制形象”中的本地宠物导入入口选择该目录。导入复制到用户数据目录，不依赖本机生成文件、Codex 宠物目录或原试用版配置。

角色通过 `characterId: "xiaobai"` 识别，内容 ID 仍由导入完整性校验生成。改显示名或新增素材不会使其他导入皮肤获得小白专属交互。

图集共 59,448,235 字节，低于现有 64 MiB 总预算；每张不超过 16 MiB。三种庆祝均为 40 帧、3063 ms。转圈使用 600×416 的宽帧，全段固定等比，保留头脚和脚底位置；仅播放期间临时扩宽透明窗口，结束、取消或失败时恢复。

素材来源是用户提供的小狗参考形象及本轮已认可的生成动作。保留最终透明图集，不收录原始视频、失败版本、生成工具、模型、个人照片或试用配置。梦境需要的两张头像及页面随源码保留。

## 整理边界

以原正式安装包和小白候选之间的增量为输入，三方移植到主线基线；保留基线已有的气泡、主题、账户等功能。

排除候选强制 `userData` 路径、临时动作注入入口、旧内容 ID 别名迁移、独立配置与账号数据、调试脚本和安装包。双击、拖动、贴边、梦境与三庆祝的角色专属改变限定为小白；通用导入和播放器只增加这些动作必要的能力并保留旧格式默认行为。

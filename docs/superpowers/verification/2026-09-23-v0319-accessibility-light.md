# 0.3.19 色弱友好浅深色与角色样式恢复

## 已确认需求

色弱友好只改变信息界面的配色，不改变球球身体、眼睛、睡眠、原有动效和聊天头像；支持浅色、深色和跟随系统；保留额度边框原动态流光。

## 实现

- 移除角色和思考粒子主题覆盖，保留原始渐变及阴影。
- “界面配色 → 色弱友好外观”新增三种外观，与已有额度卡外观共用偏好，避免两处设置不一致；未开启Codex也可设置。
- 浅色使用白底深字、蓝色操作和深金色告警；深色沿用现有高对比色板。系统外观变化即时应用，不覆盖标准配色。
- 去除对边框流光的隐藏，只保留卡片实底以稳定文字对比度。

## 验证

- 1039项单元测试通过，覆盖设置持久化、失败回滚、系统外观变化、原窗口销毁回归。
- 最终包原生 PET_COLOR_MODE_OK / PET_COLOR_APPEARANCE_PET_UNCHANGED_OK / PET_CHAT_INTEGRATION_OK，深浅色切换前后球球实际fill/stroke/eye/filter一致；聊天连续发送/历史/正常退出使用模拟RPC验证，无额外真实模型消息。
- 252组真实额度布局及4次系统主题切换通过。浅色实际文字对比度6.89–16.32，深色9.08–16.97；数字和状态字无裁切。
- 动态流光先验证失败再修复通过：before/after均保留conic-gradient、quotaBeamOrbit，连续帧角度变化。

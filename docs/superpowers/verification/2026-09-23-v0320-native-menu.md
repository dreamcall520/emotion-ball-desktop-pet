# 0.3.20 macOS 原生右键菜单展开修复

## 问题与修复

用户在 macOS 27.0（26A428）、Electron 43.4.1、80×80 球球窗口上看到菜单只剩小块玻璃，一次显示一条并上下滚动。菜单数据和 AX 条目仍完整。

popupPetMenu 改用 positioningItem: 0，让 AppKit 定位首项，跳过 Electron 对长菜单的手动底边补偿。保留原生玻璃样式、菜单内容、窗口尺寸以及靠边展开保护。此前单独传 frame 的候选由用户确认仍裁切，已撤销。

定位依据：[Electron 43.4.1 的原生位置计算](https://github.com/electron/electron/blob/v43.4.1/shell/browser/api/electron_api_menu_mac.mm#L150)。源码确认默认补偿行为；AppKit 内部触发滚动的细节没有直接测量。

# 0.3.18 配色与额度可读性

## 改动

- 默认深色额度卡的副周期告警颜色遗漏，导致深棕色15%与灰底近似。统一主题变量，浅色保留深色文字，深色低额度与紧急状态改为明亮文字。
- 额度同时标注偏低、紧张、已用尽；紧凑摘要依据展示周期，而不是另一个周期的告警色。
- 新增菜单“界面配色 → 标准配色 / 色弱友好（高对比）”。持久化设置colorMode，默认兼容旧版，切回标准恢复已有的额度外观偏好。
- 全局覆盖宠物、额度、聊天、互动气泡、靠边胶囊及思考效果。高对比使用不透明深底、黑白文字和蓝黄辅助色，包含清晰焦点/禁用按钮与宠物轮廓。

## 验证

- Node 测试1032项通过；包括旧配置兼容、设置保存失败回滚、窗口关闭/重载/延迟创建和六个preload接收白名单。
- 隐藏真实Electron额度矩阵252项通过：标准/高对比/恢复标准 × 深浅外观 × 周期/额度/尺寸。高对比实际文本对比度9.08–16.97:1，可见数字及状态字无裁切。
- 0.3.18最终包原生PET_COLOR_MODE_OK、PET_CHAT_INTEGRATION_OK：使用模拟RPC验证配色菜单、宠物/聊天即时同步、连续聊天、历史切换及正常退出；未向真实模型发送验收消息。
- 临时签名严格校验通过。无需新增系统权限；安装状态和完整证据另见交付目录验收记录/v0.3.18-accessibility。

## 设计依据

参考[WCAG文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)与[不单靠颜色表达信息](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)。本次仅验证相关配色与状态标识，不代表完整无障碍认证。

## Rosetta 烟测

- 首次对原始 x64 应用执行完整烟测时，系统真实进入锁屏；活动监测按设计将动作暂停，流程停在 `bow`，renderer 错误数为 0。这不是应用崩溃或打包失败。
- 使用 `caffeinate -dimsu` 防止测试途中休眠后，原始 x64 应用完整烟测退出码为 0，并输出 `PET_SMOKE_OK`。
- 完整通过范围包括：正式设置隔离、内侧朝向、侧躺贴贴、放下站稳、唤醒绕圈、六类原动作、五档尺寸、拖拽/气泡、负坐标副屏、Codex 思考光迹、额度卡片、任务菜单、睡眠视觉与原生窗口弹跳。
- 关键 PNG 已人工查看：左右注视与朝向、思考光迹、贴贴姿态、深色额度卡片和长标题气泡均正常。
- 对逐字节一致的交付主应用追加复验时，完整流程已再次跑过全部普通互动、五档尺寸、负坐标副屏和 Codex 额度/思考步骤；重复运行在 Codex 跳跃自然结束与普通气泡显示处出现两个非确定性时序断言。随后 Codex 专项复跑已输出 `PET_CODEX_SIMULATED_OK`、两档睡眠视觉、`PET_BOUNCE_OK` 和 `PET_SMOKE_OK`。
- 当前 `PET_SMOKE_CODEX_ONLY=1` 只跳过普通互动，但外层脚本仍无条件要求普通互动标记，因此专项复跑在应用已输出 `PET_SMOKE_OK` 后由外层断言返回 1。该问题记录为烟测脚本边界，不改变前述完整退出码 0 的 Rosetta 结果，也不把失败步骤写成通过。
- 所有烟测均使用独立临时用户目录，没有写正式设置。

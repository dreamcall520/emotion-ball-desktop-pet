# 球球靠边功能实施计划

Goal: 实现已确认的左右靠边、悬停探出和暂时隐藏，可在本机候选版本验收。
Architecture: 主进程独立 edge-tuck 控制器管理状态、吸附坐标和悬停延迟；屏幕内窗口保持正常大小，渲染层裁切半身。固定 IPC 同步展示状态；原有活动采样驱动鼠标检测。隐藏逻辑集中拦截辅助窗和主动动作。
Tech: Electron / JavaScript / node:test。

1. 实现与单元验证（子 Agent）：先写状态边界与主进程整合行为测试，再最小修改 main/preload/renderer/pet.css，新增 focused edge-tuck 模块。覆盖拖动、左右/负坐标、悬停延迟、透明区穿透、隐藏/恢复、锁屏/尺寸/显示器恢复、辅助窗。运行相关与完整测试，自检提交。不得改正式版、打包版本号、native acceptance 脚本或本计划。
2. 独立验收（主 Agent）：准备/运行真实 Electron 验收，检查半身画面、展开与取消、隐藏及恢复，保存截图和可复核输出；原有 smoke 回归。必要时以测试专用闭包接入，无新增生产调试 IPC。
3. 先规格符合性，再代码质量复核（独立 Agent）：发现问题交实现者修复并复核。
4. 本地候选交付：保留正式 0.3.13 与 Intel。记录源码提交、测试、原生验收证据和候选使用入口，不宣称已发布或已替换安装版。

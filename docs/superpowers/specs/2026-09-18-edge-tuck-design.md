# 球球靠边收起与暂时隐藏

用户已选择研究建议并要求“可以先做这个，能支持球球靠边”。本次直接实施该范围。

- 真正拖动后在左右工作区边缘 16px 内松手，吸附该侧；鼠标离开后露出半个球，靠近可见部分时完整探出。
- 悬停展开，离开约 650ms 后收起；拖动时停止收起，拖离边缘回到自由状态。普通点击不能误触发吸边。
- 收起和暂时隐藏时，气泡、思考光迹与额度卡一起隐藏，后台 Codex 状态继续更新。重新展开恢复当前有效额度与状态，不重放收起前已经显示的旧气泡；从未展示且仍有效的 Codex 提醒继续遵循原来的过期与去重规则。
- 菜单提供靠左、靠右、离开边缘、暂时隐藏与显示球球。托盘显式恢复取消靠边，确保随时可找回。
- 复用当前灰白外观与朝向；大小 60/80/120/180/260 均保持。采用屏幕内完整方形窗口 + 内容横向裁切，不让半身越入相邻屏幕；收起时透明区域鼠标穿透。
- 锁屏/休眠、窗口关闭、显示器移除、尺寸修改、安全恢复时清理计时器与动作。靠边状态本次为会话状态；仅保存完整可见的位置，重启以完整球球出现。隐藏也不持久化。
- 不修改 Codex 授权、配色、官网、Intel 分支或正式版产物。

验收：左右收起/悬停/离开/拖走；真实拖动与点击区分；辅助窗不会漏出；隐藏后后台刷新不弹出；恢复不离屏；负坐标/共享屏幕边缘和五种尺寸；原有互动与 Codex 回归。

# 商店 WorkBuddy 任务动画、聊天与公共互动

2026-11-21。基于同一独立分支，用户在积分/任务接入后明确追加本页范围。本页覆盖早期仅积分、不开放聊天/事件插件/游戏的限制。

## 授权边界

主连接选择本机 WorkBuddy.app 和账号目录，一次披露并同意积分查询与聊天；任务列表仍单独只读任务元数据。新增动画提醒明确同意安装自有本机 Hook，原始事件输入只在源进程内过滤，球球只接阶段与轮次标识；注册与配对写入独立授权的 `.workbuddy` 自有范围，备份并保留原设置、其他 Hook 和插件，撤销精确清理自有项。聊天同意绑定当前账号，使用官方积分，将当前会话消息送往实际官方服务 `https://copilot.tencent.com`。旧版仅积分授权不得自动升级为聊天授权，显示“继续连接”，重新同意统一说明后复用已有目录授权；没有独立聊天设置卡。

商店仍使用 MAS runtime/App Sandbox。仅为受限本机事件接收与自有 Hook 写入增加必要权限，不引入厂商运行时或旧 CLI；模型/聊天复用官网现有 companion 和已授权安装组件。

## 动画与聊天

提交进入处理中反馈，实际工具事件标识活动，等待、超时和断线单独归类。只有已观察同一账号/轮次开始、随后收到非恢复的正常 FinalStop，才提示本轮主回复完成；普通 Stop、取消、失败及历史缓存不产生成功动画。每个事件先用本机 account-check 验证当前账号，轮次、授权代次与页面代次隔离迟到事件。WorkBuddy/Codex 独立状态汇总思考，完成展示串行避让用户动作，复用当前皮肤；没有所有后台任务都完成的承诺。

聊天模型、流式回复、停止和本地会话沿用官网。models/chat 需要主连接中明确保存的聊天用途同意与当前账号，撤销后的同账号重授权也不能接受旧请求/旧delta。聊天来源可在 Codex 与 WorkBuddy 切换，其他来源继续裁剪。主连接以本机 account-check 核验账号，不等待独立网络积分首查；取消或身份变化须撤销本轮聊天同意。完成提示使用单行短句“WorkBuddy 有新结果”，不改共享气泡样式。

## 公共互动与视觉反馈

额度趣味互动移到联动样式管理，公共开关控制唯一入口，按用户顺序跟随第一张实际可见的额度卡（天气除外）。Codex 继续真实百分比玩法，WorkBuddy 沿用官网自由玩法，不把积分余额伪造成百分比。

WorkBuddy 详情重新打开默认每日消耗；同次打开的数据刷新保留选择。共享说明浮层在窗口关闭/隐藏后收起，样式更紧凑。普通云朵减轻过重外沿；统一咩咩/小白放大预览为205px并恢复缩略图等比，实际桌面档位和原素材保持。

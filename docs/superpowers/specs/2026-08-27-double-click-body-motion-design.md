# 球球双击全身动作增强

日期：2026-08-27。五类动作方向及本文件已获晓坤确认，进入实施；完成状态以当次验收结果为准。

## 目标与边界

解决现有双击主要换眼神、偶尔弹跳或旋转，身体反馈不足的问题。沿用现有球球形象和桌面应用，只增强主动双击动作及其对应气泡。

- 新增或升级五类全身动作；既有旋转作为低频彩蛋保留。
- 身体始终使用已确认的灰白色 `#EEEBE4`，保持黑色眼睛、现有渐变和轻阴影。
- 不改变尺寸档位、当前尺寸、置顶、气泡开关、闲置睡眠规则和眼神跟随；不增加主动打扰频率。
- 不增加满屏巡游、追逐鼠标、声音、联网或输入内容读取。
- 本次目标为本地体验更新；不推送 GitHub、不更新公开 Release 或分享 ZIP。

## 动作设计

每次只播放一段完整动作，时长控制在 1.4–2.0 秒；有准备、主动作、收尾，不能仅靠眼神变化区别。

| 动作 | 身体变化与节奏 | 配合眼神 | 对应文案示例 |
| --- | --- | --- | --- |
| 开心连跳 | 先下压蓄力，两次由高到低的跳跃，每次落地压扁后回弹 | 睁眼、开心 | 看我蹦两下！ |
| 果冻抖抖 | 原地横向压扁、纵向拉长，交替两轮并逐渐收敛 | 惊讶后放松 | 我是软乎乎的！ |
| 左右扭扭 | 身体左右倾斜并小幅横移，左右各两拍，最后回正 | 跟随摇摆方向 | 给你跳个小舞～ |
| 歪头探望 | 整个身体向一侧探出并短暂停顿，再探向另一侧后缩回 | 向探身方向看 | 让我瞅瞅～ |
| 点头鞠躬 | 身体下沉、纵向收缩模拟前倾，轻点两次后回正；与左右倾斜区别开 | 温和回应 | 收到，向你致意！ |

以上是文案与动作的对应语义，不只更换这五句话；优先复用现有适合的短句，小范围补充动作专属文案。清醒互动不用睡眠文案。

## 触发、打断与气泡

- 清醒时双击抽取动作：五类动作各权重 2，旋转权重 1；排除上一次双击动作后再抽取，避免连续重复。
- 单次双击不叠加排队中的单击动作。动作中再次双击，取消旧动作和回调，再执行新动作，不叠加位移或形变。
- 睡着时双击仍先唤醒，不改成随机入睡；手动睡眠仍从菜单进入。
- 单击原有玩法保留；双击后的“再来一次”重播对应的完整动作，不退回旧的随机眨眼或转圈。明确要求重播不受“不连续重复”限制。
- “你歇会儿”、拖动、手动睡眠、锁屏、隐藏、缩放或退出都取消正在播放的动作和旧回调。正常结束回到本次开始位置；拖动中断后服从新的拖动位置，不被旧回调拉回。显示器变化时服从现有可见区域恢复规则。
- 气泡复用现有独立窗口、14px 字号、按钮和节流。动作类别决定文案类别；若冷却期不能显示新文案，收起旧动作的专属气泡，避免动作与文字错配。关闭气泡不影响动作。

## 小尺寸与窗口边界

- 80×80 为首要验收尺寸：即使不看文案和眼睛，也能从身体轮廓与位移分辨五类动作。
- 身体形变和小幅探身受现有绘制区域约束，保留边缘安全余量，不靠扩大透明窗口或永久缩小球球规避裁切。
- 跳跃延用移动整个桌宠窗口的方式，避免在固定小窗口内向上移动图形造成截头。起跳、落地与身体压缩使用同一动作时间轴。
- 靠屏幕边缘时按所在显示器工作区收敛位移；空间不足可缩短跳跃距离，但保留蓄力和落地形变，不能越界或跳到另一块屏幕。
- 不抢焦点；动作过程不把临时跳跃坐标持久化为新的停留位置。

## 最小实现划分

1. 动作目录与时间曲线：在桌宠侧独立小模块中定义动作、抽取权重和随时间变化的身体姿态、窗口偏移；可脱离界面验证。
2. 现有绘制与调度：复用 `emotion-ball/js/engine.js`、`ball.js` 的姿态管线与 `desktop-pet/renderer.js` 的交互入口，仅补充所需的横纵独立缩放和受控动作播放；未启用新动作时原表情表现不变。
3. 窗口移动：扩展现有 `desktop-pet/lib/window-bounce.js` 与 `main.js` 的移动、停止和位置恢复逻辑；动作标识经过白名单校验，非法请求忽略。
4. 气泡映射：复用既有文案选择及按钮生命周期，只增加动作类别关联。打包清单纳入新增运行文件，避免再次出现模块遗漏。

流程为：双击 → 取消旧任务 → 选择动作 → 同步身体、窗口和对应气泡 → 完成回正或被用户打断。每次动作拥有独立有效标识，旧计时回调不得影响新动作。异常或窗口销毁时停止计时，恢复安全姿态，不残留抖动或位置漂移。

## 验收与交付

- 先补测试再实现：动作选择与去重、权重、完整起止、重播、双击取消单击、连续触发、拖动中断、睡眠/锁屏/隐藏/缩放停止、旧回调失效、气泡开关与节流。
- 检查每种动作全程的身体边界和颜色；验证 80×80 及其他现有尺寸档位，结束后位置、形状和设置正确。
- 在真实 Electron 窗口逐个强制触发五类动作和旋转，查看关键帧及完整播放；不以随机抽到几个动作、截图文件生成或仅测试通过作为视觉验收。
- 检查白底、深底、屏幕四边及多显示器负坐标；确认不裁切、不越界、不抢焦点，眼神跟随、睡眼和 Zzz 没有退化。
- 验证打包版可启动、模块齐全、签名正确，再更新本机应用；替换前保留可恢复旧版，保留当时的最新用户设置，避免新增可搜索的重复应用。
- 交付时分开说明代码、实际视觉、打包与本机安装的验证结果；尚未完成的环节明确标注。

# 球球桌宠：可选 Codex 联动

日期：2026-08-28

状态：用户已确认本书面方案及临时接收状态包的读取范围。2026-08-29 用户手动打开 A/B 后，修复任务来源识别、轮次记录兼容及短暂空闲过渡，真实运行/完成、两任务合并气泡、跳跃和关闭清理已通过；491 项检查通过。未打开的新后台任务此前验收失败，不能外推已修好；旧偶发问题、真实等待/失败/中断及实际跳转仍待验。安装版和分享包未动，仍为源码候选，不是完整实机交付。

## 1. 目标与范围

- 为使用 Codex 的用户提供额度预警，以及处理中、等你确认、本轮结束、执行失败提醒。
- 增加「Codex 联动」总开关，默认关闭；不使用 Codex 的用户继续使用普通桌宠。
- 保持灰白色、四档尺寸（含 80×80）、原有单击/双击、拖动、睡眠和气泡行为，优先复用已有动作。
- 第一版只覆盖这台 Mac 上可验证的 Codex 任务；不宣称支持云端、其他电脑或所有第三方客户端。
- 只读提醒是已选方向。另一种方案是让球球直接创建任务、发送消息和代做确认，但会引入权限及误操作风险，本期不做。

## 2. 菜单与开关

沿用菜单栏与球球右键共用的菜单，在现有「互动气泡」附近增加：

- 「Codex 联动」：勾选开关。
- 「Codex 状态」：仅开启后显示的子菜单，第一版包含额度、下次重置时间、任务状态、最近提醒和手动刷新入口。2026-08-29 用户确认移除重复且不可操作的「最近提醒」；任务列表只保留「处理中」和「等你确认」，其余入口保留。

第一版只增加持久化设置 `codexEnabled`，默认 `false`。旧设置缺少此项、值类型错误或设置读取失败时均关闭；不改变尺寸、位置和其他已保存设置。后续经 2026-08-29 确认的额度展示、提醒周期与任务名称显示开关，按新版设计稿分别保存用户选择。

### 关闭

- 不检测 Codex 安装、不读取其文件或账号、不发起额度/任务请求、不创建联动连接、子进程、监听器或重试定时器。
- 运行中关闭时，立即取消本模块的请求、定时器、排队提醒和动作；清除内存中的账号、额度及任务快照，让联动气泡及按钮失效。
- 只关闭球球拥有的连接/辅助进程，不退出、重启或修改 Codex 本身。使用连接代次标识丢弃关闭后迟到的结果。
- 不清除用户正在看的普通互动气泡，不停止用户主动触发的动作；只撤销属于联动的表现。

### 开启

- 用户勾选后先说明并取得同意，再检测并连接，菜单显示「正在连接」。说明：状态包可能附带已加载聊天内容，仅在本机临时接收，只提取任务进展，正文立即丢弃、不保存、不上传；不监听键盘、不代替用户操作任务。每次由关闭切换到开启均确认，已同意且保存开启状态的重启不重复询问。
- 已安装且已登录时复用 Codex 自身的账号能力；球球不收集密码、不复制登录凭据，不自动登录或登出。
- 未安装、未登录、版本不支持或连接失败时在子菜单明确说明，球球原有功能继续可用；不自动安装 Codex，不反复弹错误窗口。
- 开关保存用户选择，重启后恢复；开启但连接失败不擅自取消勾选，也不伪装成已连接。
- 网络或服务暂时失败时按三十秒、六十秒、一百二十秒退避重连，之后最多每两分钟一次；缺少软件、未登录或版本不支持时停止自动重试，只等待用户手动刷新、重新开启或下次启动。
- 现有「互动气泡」仍是气泡总开关：关闭气泡时仅保留菜单状态和符合安静规则的动作，不影响是否读取 Codex。关闭 Codex 联动则所有联动均停止。

## 3. 数据可信度与接入门槛

官方提供额度读取、任务状态和事件接口，见 [OpenAI Docs：App Server](https://learn.chatgpt.com/docs/app-server)。这些接口的存在不等于独立连接能看到桌面应用的实时任务。

同一会话上一轮的只读探测：额度快照读取成功；独立连接返回的任务样本均为 `notLoaded`，默认共享连接入口也未连通。这只是可行性证据，不能称实时提醒已验证。

进一步核验：桌面 IPC 的状态订阅会附带已加载会话内容。用户现已明确同意「本机临时接收状态包、只提取进展、立即丢弃正文」；已验证当前任务的 active 增量，以及用户手动打开的专用 A/B 的真实完成和合并提醒。未打开后台任务、等待、失败、中断与实际跳转仍须分别核验，详见 [接入核验记录](../verification/2026-08-28-codex-readonly-connection.md)。

- 额度与任务分别报告连接状态。例如「额度已连接；任务进展未连接」。失败不拖垮另一项。
- 额度使用 `account/rateLimits/read` 的实际类别、窗口、已用比例及重置时间。缺失字段显示「暂不可用」，不假定所有账号都有固定的五小时/每周额度。
- 任务读取优先使用已运行桌面服务提供的只读通路；读取不调用 `thread/resume`，不新建任务，不恢复或订阅会改变任务运行条件的会话。
- 独立服务可作为额度来源，但不能用其 `notLoaded` 结果推断桌面任务已结束；`idle` 也不能单独证明整项工作完成。
- 开发第一步先验证真实任务的开始、等待、结束及失败变化。只有能可靠读取这些变化，才启用相应提醒能力。
- 若不能接通实时任务，保留明确的不可用状态并报告阻塞；不得以模拟状态、聊天文件修改时间、猜测的完成率或模型编写的进度替代，也不能将仅有额度的版本称完整交付。
- 本期不扫描聊天文件、监听打字、修改 Codex 数据库/配置、读取凭据文件或上传用户数据。不额外请求完整历史；已加载状态包及元数据附带的正文/预览立即丢弃，不进入展示、缓存或日志。允许的请求方法使用明确白名单，联动不发起模型任务。
- 实测部分长历史任务的状态包接近 200MB。第一版采用有界降级：正常包最多解析 16MiB；更大的合法帧只读取最多 8KiB 协议头定位任务，其余流式丢弃，该任务显示「状态包过大，暂不可用」并取消跟随，不影响其他可靠任务。不能安全识别头部或超过 256MiB 则断开并显示不可用；不反复自动请求已隔离的大包。此类任务不承诺进展提醒，不能算完整覆盖。

## 4. 状态与动作

以下均以取得可靠状态为前提；首次连接只建立基线，不把历史完成记录当新提醒。

| 真实状态 | 球球表现 | 气泡与入口 |
| --- | --- | --- |
| 正在处理 | 进入时轻晃一次，随后安静陪伴 | 不反复弹气泡；菜单显示处理中 |
| 等用户确认/回复 | 复用歪头探望 | 「有一步等你确认哦」＋去看看 |
| 当前轮次正常结束 | 复用开心连跳 | 「这轮有结果啦，去看看？」＋去看看 |
| 当前轮次明确失败 | 复用果冻轻抖 | 「这一步遇到问题了」＋去看看 |
| 额度低于阈值 | 复用点头提醒 | 气泡显示剩余比例，完整额度类别和周期在「Codex 状态」菜单中查看；多类合并时明确是最低剩余比例 |
| 未连接或状态过期 | 恢复普通桌宠表现 | 仅在菜单标识，不误报完成 |

- 本轮结束与整个任务完成分开，不展示没有来源的完成百分比或剩余工时。中断不庆祝，自动重试中的瞬时错误不按最终失败提示。
- 同一轮已观察到运行/等待后，允许跨过至多五秒的短暂空闲再接收明确终态；空闲本身不产生完成提醒。重复空闲不续期，未知、重建基线、断连、刷新、换账号、关闭或移出任务立即清除该证据。
- 「任务列表」只展示可靠状态为「处理中」或「等你确认」的本机用户任务；完成、失败、中断、空闲、未知或不可用任务立即从可见列表移除。连接不可用与确实没有进行中任务使用不同空状态，不能把未知误报为空列表。
- 监测本机用户任务，排除归档记录和内部子代理；同时处理多个任务时合并提醒，不逐个连续跳动。
- 直接点击、拖动及正在播放的用户动作优先；联动不能中断它们。睡眠、锁屏和隐藏时不强制唤醒或播放联动动画，菜单保留状态；恢复后不补播已过期提醒。
- 联动结束回到原有行为，不修改「保持清醒」设置；不改变身体颜色、尺寸、用户位置或眼睛绘制方案。

## 5. 额度、频率与隐私

- 额度按 Codex 返回的每个类别、每个周期分别展示，不把 Token 总数、上下文占比和账号额度混为一谈。
- 低额度阈值为剩余不高于 20%、10%；一次跨过两档时只提示更严重的一档。同一周期同一档只提示一次，恢复连接不重复提示。
- 第一次开启时若已低于阈值，只提示当前最严重档一次；关闭后清除本次联动内存。再次开启建立新基线，可提示当前低额度，但不回放历史任务提醒。
- 额度正常每两分钟刷新，手动刷新最短间隔十秒；失败保留最后更新时间，五分钟未成功刷新即标记过期并停止基于旧额度发预警。事件更新可提前刷新显示。
- 任务优先接收可靠事件；如需只读轮询，正常间隔不短于五秒，限制单轮工作量，并明确快照不完整时不能显示为全量计数。
- 所有自动提醒共享至少三十秒间隔；五秒内同类任务提醒合并。用户互动导致延后的提醒最长保留六十秒，超时仅留菜单，不突然补播。
- 气泡显示八秒，不播声音、不激活窗口。仅用户点击「去看看」才打开 Codex；任务链接从可信任务标识构造，不能执行接口返回的任意地址或命令。
- 合并多个已完成任务时按钮为「查看结果」，只在当前提醒有效期内展开本次提醒对应的临时结果菜单，由用户选择任务；它不写入「任务列表」或提醒历史。单任务时「去看看」直接定位对应任务。打不开时明确说明，不发送消息或自动续跑。
- 第一版曾在内存保留最新十条提醒；2026-08-29 用户确认该列表信息重复、缺少操作价值，因此后续移除「最近提醒」菜单及对应历史缓存，不设置替代入口。进行中及待确认任务看「任务列表」，当前额度看额度状态。
- 第一版气泡使用通用短句，不展示任务正文或敏感标题。2026-08-29 用户确认后续可通过默认关闭的独立隐私开关，在可靠的任务完成提醒中显示经过清理和截断的任务名称；不开启时仍使用通用文案，任何情况下都不展示正文。详细规则以 `2026-08-29-quota-display-alerts-design.md` 第 5 节为准。菜单按需显示任务标题并按纯文本处理；完整内容仍在 Codex 中查看。
- 只持久化用户明确选择的联动总开关、额度展示与周期、任务名称显示开关；不将账号、额度快照、任务标题、正文或凭据写入球球设置、日志、安装包或分享包。切换账号时清空旧快照与提醒基线。

## 6. 实现边界

- 设置与菜单：最小扩展现有 `desktop-pet/lib/settings.js` 和 `desktop-pet/main.js`。
- 连接模块：独立负责发现安装、只读请求、超时、断连及释放；导入模块本身无读取/连接副作用。只在总开关开启后实例化。
- 状态模块：将额度与任务证据规范化为独立快照，保留来源、能力范围和最后成功时间；未知状态不能降级成成功。
- 提醒模块：负责阈值、去重、合并和优先级；复用现有 `DialogueDirector`、气泡窗口和六类动作，不另建一套持续动画时钟。
- 气泡动作新增受控的「去看看/查看结果」「知道啦」，兼容原「再来一次」「你歇会儿」；校验当前提醒、开关状态和动作归属，拒绝过期按钮。「查看结果」使用当前提醒内的可信任务标识构建临时菜单，不复用只显示进行中任务的常驻列表。
- 不捆绑另一份 Codex 运行程序，不新增常驻外部服务，保持普通桌宠可独立运行，避免分享包明显增大。

## 7. 验收与交付门槛

1. 旧配置升级及全新安装默认关闭；关闭启动时，用可观测测试证明对 Codex 的发现、读取、请求、监听和子进程创建次数全部为零。
2. 开启后关闭、快速连续开关、请求未结束时关闭、退出球球：资源释放、迟到结果丢弃、无残留联动气泡；不影响 Codex 及普通互动。
3. 无 Codex、未登录、账号切换、版本不兼容、断网、字段缺失、重连及过期快照均准确展示，球球不崩溃、不抢焦点。
4. 验证多类额度、不同周期、20%/10%跨档、重置、重复快照和气泡总开关；没有真实数据时不产生额度数字。
5. 在真实桌面任务上验证处理中、等待、轮次结束、失败、中断和并发；初次连接不补报历史，`notLoaded`/断连不误报结束。不可见状态明确标记能力缺失，不算通过。
6. 真实检查任务列表只出现「处理中」和「等你确认」，终态/空闲/未知立即移除且断连不误报为空；「去看看」能到正确任务，多任务「查看结果」只展开当前提醒的临时选择菜单；关闭联动后的旧按钮无效，不执行任务控制操作。
7. 回归四档尺寸、80×80气泡可读性、双屏边界、动作完整性、拖拽、睡眠/Zzz、灰白色和既有互动；确认无裁切、位移累积或焦点抢占。
8. 源码测试、真实窗口验收、打包内容及安装替换分别记录。专门创建会消耗模型额度的测试任务须另行告知并征得同意；不把测试通过称为已安装。

代码完成后按既有约定同步当前 Git 功能分支；安装版、分享 ZIP、主分支和公开 Release 分别报告，不因方案确认自动发布。

# 靠边时的轻陪伴

用户补充要求：收起仍偶尔眨眼、轻微呼吸，不定时出现互动文案；已开启 Codex 额度显示时偶尔显示剩余额度。本文件更新原靠边方案中“完全静止、全部辅助内容关闭”的约定。

- 只在靠边露半身时保留安静动画：根据用户后续反馈，清醒时改为约 2.5–5 秒眨眼、微幅呼吸；睡眠时闭眼微呼吸。暂停、锁屏、完全隐藏时停止。收起仍不运行大动作、追视或 Codex 思考光迹。
- 靠边形态按用户截图精修：上下与屏边相接处采用圆润曲线，头部略收短，双眼适度缩小下移且完整露出；直接按靠边侧确定内侧朝向，包含旧位置采样和锁屏恢复场景。自由/展开状态恢复原圆形，保持原配色。
- 短句遵循“互动气泡”开关，约 3–6 分钟一次，每次 4.5 秒。首次符合条件后 60–90 秒；避免连续重复文案。
- 额度遵循 Codex 联动与“显示剩余额度”两个现有开关，约 5–10 分钟一次，每次 6 秒；首次 30–60 秒。只读现有快照，沿用主周期选择规则，只展示 ready 的真实有效额度；过期、失联或无所选周期时不弹百分比。
- 两种提示共用一只玻璃小胶囊，彼此至少间隔 90 秒，出现在露出半身的内侧。短句为一行；额度为 Codex、周期和剩余百分比。沿用现有浅/深/系统外观，不展示大卡片、按钮或思考特效。
- 胶囊不抢焦点、鼠标穿透，不自动展开球球。展开时立即撤回，原额度卡恢复；隐藏、锁屏、关闭设置、窗口关闭/重载时清理。重复靠边不补播旧提示。
- 复用活动采样驱动节奏，不增加轮询或权限，不改变后台 Codex 数据获取。
- 验证涵盖随机节奏、互斥、设置/数据失效/生命周期、真实 Electron 左右/浅深胶囊与动画；更新独立体验包，保留体验设置与正式安装版。

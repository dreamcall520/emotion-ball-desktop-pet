# 球球桌宠：额度卡片外观设置

日期：2026-08-29

状态：用户已确认功能方向、影响范围和本书面方案，同意进入实施。尚未修改程序、安装版或分享包。

## 1. 目标与范围

- 在现有「Codex 联动」设置中增加额度卡片外观选择，让用户可以使用「跟随系统」「浅色」「深色」。
- 默认选择「跟随系统」。macOS 切换浅色或夜间模式时，卡片继续实时跟随。
- 外观设置只影响桌面额度卡片的收起与展开状态，不改变球球、互动气泡、右键菜单、菜单栏或其他应用窗口。
- 保留额度卡片大小、展开状态、屏幕位置、流光、额度内容和现有浅深色视觉规则；不重做卡片布局。

## 2. 菜单与设置

在「Codex 联动」子菜单的「额度卡片大小」附近增加「额度卡片外观」子菜单：

- 「跟随系统」：默认选中。
- 「浅色」：无论系统当前模式如何，额度卡片保持浅色液态玻璃。
- 「深色」：无论系统当前模式如何，额度卡片保持深色液态玻璃。

新增持久化设置 `codexQuotaAppearance`，只接受 `system`、`light`、`dark`。旧配置缺少该字段、字段类型错误或值不在白名单时，统一回退为 `system`；其他已有设置逐项保留。

Codex 联动关闭时，外观子菜单与其他额度设置一致地不可操作，但保留用户上一次选择。重新开启后恢复该外观，不重复要求选择。

切换外观后立即刷新当前可见卡片，不需要重启应用；不重建窗口，不改变卡片收起/展开状态、大小、位置或额度数据。设置保存失败时维持原选择，并沿用现有设置失败提示，不显示已经保存成功的假状态。

## 3. 外观切换方式

- 额度卡片继续只使用一套 HTML、布局和内容渲染，避免维护三份页面。
- 主进程把已校验的外观值随额度卡片模型传给现有窗口；预加载层只允许三个合法枚举值，非法值按 `system` 处理。
- 渲染层将外观值设置到额度卡片页面根节点。CSS 通过该状态选择浅色或深色变量；不修改 Electron 的全局主题来源，避免影响球球、气泡和菜单。
- `system` 使用系统 `prefers-color-scheme`；`light` 固定使用当前浅色液态玻璃变量；`dark` 固定使用当前深色液态玻璃变量。
- 流光、边框、文字、进度条和重置详情随卡片外观一起切换。系统开启「减少动态效果」时，三种外观都继续停止流动动画。
- 浅色模式继续保证深色壁纸上的文字对比度；深色模式继续保证浅色或复杂壁纸上的卡片边界与文字可读性。

## 4. 数据与隐私边界

- 只保存用户选择的外观枚举，不保存系统主题历史、壁纸、屏幕截图或颜色采样结果。
- 不请求屏幕录制、辅助功能或其他新权限，不读取壁纸文件。
- 不改变 Codex 额度读取、任务状态、提醒阈值和账号数据处理方式。
- 普通桌宠及未开启 Codex 联动的用户不增加连接、轮询或后台资源。

## 5. 验收与交付门槛

1. 全新配置和旧配置均默认「跟随系统」；三个合法值可保存、回读，非法值回退且不会覆盖其他设置。
2. 菜单只出现一个选中项，Codex 联动关闭时不可操作；保存成功后立即更新勾选，保存失败时保持原选择。
3. 当前卡片可见时，依次切换「跟随系统」「浅色」「深色」，同一个窗口立即更新，额度文字、卡片大小、位置和展开状态不变。
4. 「跟随系统」分别在模拟浅色、模拟深色下回读实际颜色；固定浅色在系统深色时仍为浅色，固定深色在系统浅色时仍为深色。
5. 小巧收起、标准收起、两种卡片展开状态都验证三种外观；文字、进度条、重置时间和重置机会不得裁切。
6. 深色壁纸配浅色卡片、浅色壁纸配深色卡片均保留清晰边界和可读文字；「减少动态效果」在三种外观中都继续生效。
7. 源码测试、真实窗口截图、打包应用、本机安装和分享包分别验收；方案与代码完成不自动代表安装或公开发布完成。
8. 验收通过后按既有约定同步 `codex/light-companion` 分支；是否覆盖本机应用、更新分享 ZIP 或创建 GitHub Release 分别报告。

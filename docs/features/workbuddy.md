# WorkBuddy 积分与球球聊天

WorkBuddy 是独立来源；默认关闭。在设置中心的「WorkBuddy」中启用积分，或在聊天面板选择 WorkBuddy。Codex 原额度、任务与聊天连接保持独立，原聊天文件仍为 `chat.json`；WorkBuddy 使用 `workbuddy-chat.json` 和单独模型选择。

## 当前支持范围

- macOS，已安装 `/Applications/WorkBuddy.app`，国内个人登录。
- 本轮核验 WorkBuddy 5.8.3 的加密登录、个人体验版积分。未知加密格式、企业或未验证的付费积分分类明确报不支持，不猜余额。
- 模型列表来自当前账号目录。聊天只传本段文字和球球角色规则，不读取其他来源的历史、文件、屏幕或全局偏好；不提供工具执行。

## 凭据与连接

球球启动 WorkBuddy 自带 Electron 的 `ELECTRON_RUN_AS_NODE=1` 模式执行固定 helper。helper 在内存调用原生存储能力解密当前登录并请求固定官方域，令牌和密钥不跨进程返回、不写日志或页面；不会修改 WorkBuddy 登录、刷新令牌、签到或启动代理。

国内客户端内部加密和接口可能改变，不能将本轮兼容当作官方公共 API 承诺。登录到期时请去 WorkBuddy 重新登录。

## 额度

显示剩余积分、分类、基础刷新与最近一批奖励到期；不把积分硬套成 Codex 的五小时/周百分比。开启即查，每五分钟更新，失败退避；关闭中止请求。失败保留有明确失效标记的旧值，识别账号变化或登录失效清除旧余额。零余额与未取到数据不同。

## 聊天

正在连接或回复时不能切换来源。历史按来源和账号隔离；切换账号后不能继续发送原账号历史。完整历史超过本地安全上限提示新聊天，不静默丢弃旧上下文。取消、锁屏、关闭功能会取消当前及尚在准备的请求；未知结果不自动重发。取消仅表示本机停止请求，不能保证已发生的上游消耗退还。

模型输出工具调用或未完整结束时明确失败。仅完整且严格验证的 `{text,action}` 可以触发既有白名单本地动作；普通文字只显示文字。

## 验证

- `npm test`
- `PET_SMOKE_WORKBUDDY_ONLY=1 node desktop-pet/scripts/smoke-electron.js`：隔离配置、模拟取数与聊天，检查原生卡片/来源/忙碌锁和Codex状态隔离。
- 增加 `PET_SMOKE_WORKBUDDY_LIVE=1` 会使用本机真实WorkBuddy登录并发送一次短问候，消耗少量积分；仅显式启用时使用。
- `PET_SMOKE_WORKBUDDY_OUTPUT=/absolute/path` 可保存脱敏报告和窗口截图。

本轮发现干净基线 `03b7aac` 与本分支均在原 Codex 综合原生检查的180尺寸气泡避让步骤失败；不标记为全部原生检查通过。未修改原 Codex 额度核心模块或放宽断言。
